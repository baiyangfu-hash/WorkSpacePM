# 通用控制骨架（阶段树）

这是所有设备类 FB 的第一层母模板。用于新建/重构/评审时快速对齐“必须覆盖的阶段与边界”。

## 1. 初始化

关注：

- 上电初态
- 首次扫描行为
- 初始化条件
- 初始化完成标志
- 初始化失败或前置条件不足

## 2. 自动

关注：

- 自动触发条件
- 自动运行保持条件
- 步序迁移条件
- 自动完成条件
- 自动异常退出条件

## 3. 手动

关注：

- 手动模式使能条件
- 点动 / 单步 / 强制动作边界
- 是否允许绕过部分互锁
- 手动结束后的状态回收

## 4. 复位

关注：

- 复位触发条件
- 清除哪些状态 / 锁存 / 定时器
- 复位是否需要设备回安全位
- 复位后回到哪个基准状态

## 5. 模式切换

关注：

- 自动 ↔ 手动 ↔ 调试
- 切换前置条件
- 切换瞬间输出保护
- 切换后的状态一致性

## 6. 互锁

关注：

- 工艺互锁
- 安全互锁
- 上下游互锁
- 模式互锁
- 互锁失效后的安全态

## 7. 报警

关注：

- 报警触发条件
- 报警锁存条件
- 报警分级
- 报警复位条件
- 报警与动作输出的关系

## 8. 超时 / 故障

关注：

- 超时计时起点
- 超时停止或继续策略
- 反馈冲突
- 设备卡滞
- 缺失反馈

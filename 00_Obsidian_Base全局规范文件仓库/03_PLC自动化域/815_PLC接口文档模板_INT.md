## 3. 接口概述

### 3.1 文档目的
本文档描述了PLC项目中所有接口的详细信息，包括功能块、通信接口、硬件接口等，旨在为开发人员提供接口使用指南。

### 3.2 术语定义

| 术语 | 定义 |
|------|------|
| PLC | 可编程逻辑控制器 |
| FB | 功能块（Function Block） |
| Modbus | 工业通信协议 |
| OPC UA | 开放平台通信统一架构 |
| I/O | 输入/输出 |
| HMI | 人机界面 |

### 3.3 三层分工（V1.3.0 起）

接口文档分三层，各管一件事，互相之间只单向引用（方案级引用块级，块级不引用方案级）：

1. **块级**：每个 FB、每个 FC 各一份独立接口文档，文件名 `接口文档_IFC-<块名>.md`，放在该块目录的 `PRD/` 下；只写本块的输入、输出、输入输出、类型、含义（模板见 §5）。
2. **方案级**：每个项目一份 `接口文档_INT.md`，放在 `02_PLC程序/PLC_ST/00_程序方案/`；只写 FB 实例表、FC 调用表（见 §4）与跨系统交换区契约（见 §6.0），**不重复块的参数明细**。
3. **跨系统交换区契约**：方案级文档的一节，是独立契约、不属于 IO 分配表；字的定义只在这一处写，其他文档只引用。

根 `PRD/` 目录不再生成；已有根 `PRD/` 的老项目继续被驾驶舱接受，不报错。

### 3.4 高内聚、低耦合规则

1. **单一职责**：块级文档只描述本块；方案级只描述实例、FC、交换区；交换区的字定义只在契约一处。
2. **单向引用**：方案级引用块级，块级不引用方案级；FB 之间不读写对方内部变量，只通过 `VAR_IN_OUT` 结构体或交换区交互。
3. **变更影响面最小**：改一个 FB 的接口，只动它自己的接口文档与方案级实例表里的类型名；改交换区，只动契约与负责它的那个块。
4. **可检查**：方案级实例表、FC 调用表与交换区契约里写明的负责块与承载变量，在代码里必须存在（驾驶舱检查，只警告、不阻断）。

### 4.1 io_points.csv 数据字典（I/O 真源 schema）

> **定位（CHG-SPEC-2026-003 载体裁决）**：io_points.csv 是项目地址与符号的唯一机器可读真源（接线、编程、调试打点、后期查线的共同依据，对应实战表单 B3）；本数据字典为其唯一 schema 权威。驾驶舱 auto_pm 按此解析与校验，解析器三安全列扩列 = SW-2026-008 拆单 #9。023 §4.4.3 的 I/O 映射表为本 schema 的文档化子集。

| 7 | brand_model | string | — | 品牌/型号 |

**超时两段式强约束（CHG-SPEC-2026-003，与 STD-820 对齐）**：每个握手接口的超时必须拆分为 **Ack 段超时**（命令确认窗口）与**执行段超时**（动作完成窗口）分别定义，两段各自映射独立报警号，禁止合并为笼统超时值。设备间交握的时序、心跳与总超时唯一真源为 **STD-820**（8 步闭环双向握手 + 4s/4s 心跳、12s 超时）；本登记册只登记工程实例参数，不得另行定义矛盾时序。

**与 §6.0 的分工**：§6.0 管交换区里**数据在哪、谁写**；本登记册管**握手怎么走、超时多久**。两者互不重复：字的定义只在 §6.0 写一处。

## 6. 通信接口

### 6.0 跨系统交换区契约

双方约定一种通信协议，用连续寄存器地址或数组变量交换数据；每个对象一个交换区，一个交换区由双方各占一半（例如 128 个 word16，双方各用连续 64 个）。

| 对象（方向） | 协议（开放列表） | 地址区间 | 总量 | 单位 | 本机写区 | 对方写区 | 本机侧承载的变量 | 负责的块 |
|--------------|------------------|----------|------|------|----------|----------|------------------|----------|
| [对象（方向）] | [协议] | [起止地址] | [总量] | word16 | [起止] | [起止] | [变量名] | [块名] |

- **协议列是开放列表**：Modbus TCP、CC-Link、PROFINET、OPC UA 等项目实际使用的协议，不限于这几种；与上位机（IT-OT）交互时仍按 `AGENTS.md` 的基线（OPC UA 或 Modbus TCP）。
- **单位列**只填 `word16`（16 位字）或 `byte`（字节），总量、本机写区、对方写区、字定义的偏移都按这个单位计。
- **字定义只在本节写一处**（偏移、写方、名称、类型、含义）；其他文档只引用，不重复。
- 与 §4.2 的分工：本节管**数据在哪、谁写**；§4.2 管**握手怎么走、超时多久**。
- §6.1（Modbus TCP）与 §6.2（OPC UA）是协议侧的附表：协议本身的连接参数与寄存器或节点映射写在那里。

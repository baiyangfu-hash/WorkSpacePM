## 2. 项目背景与动机

电气自动化工程师在日常工作中需要管理多个 PLC 项目，涉及项目结构、工程文档、变更闭环、调试记录、质量门禁和交付证据。现有工具链分散（specmgr、pm-mgr 等），缺乏统一入口。auto-pm 旨在吸收这些分散工具，提供统一的 CLI + GUI 工作台。

## 3. 项目目标

### 3.1 核心目标

- 统一管理 PLC 项目结构（创建、检查、修复、标准化）
- 工程文档全生命周期管理（PRD/INT/DSN/TEC + PM_SESSION）
- 变更闭环管理（CHG 变更单 + 状态机 + 台账对账）
- 质量门禁自动化（ruff/mypy/pytest + 规范检查）
- 交付物打包与发布

### 3.2 非目标

- 不做在线协作（纯本地工具）
- 不做 PLC 代码生成
- 不做 CI/CD 管理

## 4. 目标用户

- **主要用户**：自动化工程师（兼 PLC+Python 开发）
- **次要用户**：AI 助手（遵循工作区根 `AGENTS.md` 的治理路由，并按当前有效、未退役的技能注册信息分域执行）

## 6. 项目结构

项目采用 5 大过程组目录结构（PROJ-016 V1.2.0）：

2026-09-01 起，`SW-2026-008` 项目母体与 `00_Infrastructure/auto_pm` 基础设施运行位双轨存在：运行源码、模板和测试默认从基础设施位加载；本目录继续承担项目文档、变更管理、历史交付和回退来源。

```
SW-2026-008_auto-pm_自动化项目管理工具/
├── 01_启动/          # 启动过程组
├── 02_规划/          # 规划过程组（PRD/INT/DSN/TEC）
├── 03_执行/          # 执行过程组（迭代计划）
├── 04_监控/          # 监控过程组（变更管理/整改项）
├── 05_收尾/          # 收尾过程组（发布说明/归档）
├── auto_pm/          # 历史母体源码副本（双轨期回退参考）
├── tests/            # 历史母体测试副本（双轨期回退参考）
├── scripts/          # 辅助脚本
├── templates/        # 历史母体模板副本（双轨期回退参考）
└── PM_SESSION_SW-2026-008.md  # 已退役的历史摘要，不是项目控制状态真源

00_Infrastructure/auto_pm/
├── auto_pm/          # 当前默认运行源码
├── tests/            # 当前默认测试集
├── templates/        # 当前默认模板
└── pyproject.toml    # 当前包元数据与版本真源
```

## 7. 技术选型

| 组件 | 技术 | 理由 |
|------|------|------|
| 语言 | Python 3.11 | 团队熟练，生态丰富 |
| GUI | PySide6 + QML | 跨平台原生UI，与PLC HMI概念对齐 |
| CLI | Click + Rich | 命令行框架 + 终端美化 |
| 数据库 | SQLite | 零配置嵌入式数据库 |
| 模板引擎 | Copier | 项目脚手架生成 |
| 测试 | pytest | 标准测试框架 |
| 代码质量 | ruff + mypy | 静态检查 + 类型检查 |
| 打包 | PyInstaller | 单文件 exe 分发 |

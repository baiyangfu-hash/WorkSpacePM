## 4. 变更原因

**变更背景**：
Cockpit OS/auto-pm 当前存在旧 A2 过期 Run 非终态、12 个 Git worktree、16 条本地分支、根工作树 557 个状态项、多个脏工作树、主线与远端漂移及运行态/源码边界混杂。User 于本会话明确授权全方位治理，但要求不得隐藏、伪造或遗留混乱。

**变更必要性**：
在 A7 候选发布前，必须先以可恢复、可审计、单主线方式完成现场冻结、历史归档、Git/worktree 清场、根运行态唯一化和治理真源对齐；禁止直接修改 SQLite、强制丢弃未知修改或切换发布指针。

**参考依据**：

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

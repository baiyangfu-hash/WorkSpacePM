## 4. 变更原因

**变更背景**：
RUN-SW008-R4-215-IMPL-01 因执行中断而保持 RUNNING；原 lease token 不可恢复，必须在自然过期后通过既有、已验证的受控结算能力将该历史 Run 收口。

**变更必要性**：
不得猜测 token、不得裸写 SQLite、不得复用原 Work/Run/Decision；需为该单一过期 Run 建立独立 Change、Decision、Work、Run 与 Checkpoint 授权链，并将允许结果固定为 CANCELLED。

**参考依据**：
SYS-2026-001 文档26/36/37；CHG-SCPT-2026-215；CHG-SAFE-2026-005；RUN-SW008-R4-215-IMPL-01 法证记录

## 6. 变更影响分析

### 6.1 项目约束影响（PMBOK五大约束）

| 约束维度 | 影响程度 | 影响描述 | 应对措施 |
|---------|:--------:|----------|----------|
| **范围(Scope)** | □无 □低 □中 ☑高 | 控制面 Run 终态；严格限定单一目标 | 独立 CHG/Decision/Work/Run；不复用原授权 |
| **进度(Schedule)** | □无 ☑低 □中 □高 | 等待自然到期后的一次性收口 | 到期前只读，不提前执行 |
| **成本(Cost)** | ☑无 □低 □中 □高 | 无外部服务、构建或发布 | 使用既有已验证能力 |
| **质量(Quality)** | □无 □低 □中 ☑高 | 错误结算会损害治理账本可信度 | CAS、双 Decision Git 快照、Checkpoint 与读后核验 |

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

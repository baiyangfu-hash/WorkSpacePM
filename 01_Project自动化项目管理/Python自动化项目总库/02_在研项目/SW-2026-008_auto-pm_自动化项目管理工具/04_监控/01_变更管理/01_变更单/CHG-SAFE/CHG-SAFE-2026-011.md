## 4. 变更原因

**变更背景**：
V04-R0 Run RUN-SW008-PMF-V04R0-001 remains RUNNING after lease expiry; its event stream has no RUN_STARTED and it has no Checkpoint. A read-only process snapshot found no matching process.

**变更必要性**：
Use a separate Recovery CHG/Decision/Work/Run to settle only this expired Run to CANCELLED with CAS and fencing. Preserve old events and never touch the original SW-2026-009 business Run.

**参考依据**：
WBS V2.5.0 V04-R0/C09 convergence; DEC-20260923-4E4C5345; user approval in current task for this exact target.

| 约束维度 | 影响程度 | 影响描述 | 应对措施 |

| **进度(Schedule)** | ☑低 | V04-R0 恢复前置 | 证据不全时停工，不以新业务 Run 遮盖 |
| **成本(Cost)** | ☑低 | 本机受控治理操作 | 不部署、不切换 release |
| **质量(Quality)** | ☑中 | 需验证终态和旧持有者失效 | 查事件、租约 epoch、CAS 与幂等回放；后续测试独立门禁 |

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

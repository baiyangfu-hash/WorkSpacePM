## 4. 变更原因

**变更背景**：
CHG-SAFE-2026-004 在历史 release 1.2.3-d41eb38 执行最小 RX ACL 授权时，发现目标根目录 DACL 从受保护状态漂移为自动继承；发布内容、Git 与发布指针未漂移，但缺少逐对象 ACL 前态快照，不能安全递归回滚。

**变更必要性**：
必须将 ACL 事故恢复与 lease token 交接缺陷分解为独立、可验证、可停止的 WBS；在获得可信 ACL 基线前禁止继续修改历史槽权限。

**参考依据**：
SYS-2026-001 文档26/36/37；CHG-SAFE-2026-004；RUN-SW008-SAFE-004-ACL-01 失败证据；DEC-20260912-A13ADFAC

| 项目 | 当前值/描述 |

| 关键参数/配置 | 根目录前态 SDDL 为 `D:P`，仅 OWNER RIGHTS、SYSTEM、Administrators 三条显式 FullControl；当前发生自动继承漂移；发布字节、Git 与三个发布元数据 SHA-256 均未漂移 |

| 关键参数/配置 | 先由只读 WBS 取得可复核基线，再建立独立 Decision/Work/Run；无逐对象基线时停止，不执行推测性递归回滚 |

## 6. 变更影响分析

### 6.1 项目约束影响（PMBOK五大约束）

| 约束维度 | 影响程度 | 影响描述 | 应对措施 |
|---------|:--------:|----------|----------|
| **范围(Scope)** | □无 □低 □中 ☑高 | 仅限历史槽 ACL 元数据与治理证据；不得扩展至发布、A2 或代码 | WBS 单阶段、每阶段停表、Decision 精确列路径 |
| **进度(Schedule)** | □无 □低 ☑中 □高 | 先等待失败 Run 租约自然失效并取得可信 ACL 基线 | 无基线不得开始恢复阶段 |
| **成本(Cost)** | ☑无 □低 □中 □高 | 仅本地取证与治理时间 | 不引入构建、部署或外部服务 |
| **质量(Quality)** | □无 □低 □中 ☑高 | 不可验证的 ACL 回滚会损害历史槽审计可信度 | 逐对象前态、后态和哈希均为必验项 |
| **风险(Risk)** | □无 □低 □中 ☑高 | 递归 ACL 命令可能删除既有 ACE 或引入父级继承 | 禁止 `/T` 批量回滚；无基线即失败关闭 |

**风险等级**（PMBOK风险评估）：□无 □低 □中 ☑高

**缓解措施**（风险应对策略）：
冻结历史槽；先留存只读当前 ACL 清单和根前态 SDDL 证据；只接受可信备份或已签署的标准 ACL 基线；恢复 Run 只可按逐对象计划执行，任一对象不匹配立即停止；发布内容、发布指针和 A2 永不在本单范围。

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

## 4. 变更原因

**变更背景**：
RUN-SW008-SAFE-004-ACL-01 在失败后因 lease token 仅存在于执行代理瞬时上下文，无法安全交接以转换终态；系统正确拒绝猜测 token、裸 SQLite 与伪造结算，但留下租约过期前的 RUNNING 记录。

**变更必要性**：
需独立建立 R4：保证失败或交接场景的 lease 秘密不会泄露，同时允许在明确的受控恢复路径中可靠结束 Run；不得借此放宽 token 校验或影响 A2 生产结算。

**参考依据**：
SYS-2026-001 文档26/36/37；CHG-SCPT-2026-214；CHG-SAFE-2026-005；RUN-SW008-SAFE-004-ACL-01 失败证据

#### 如何选择技术领域?

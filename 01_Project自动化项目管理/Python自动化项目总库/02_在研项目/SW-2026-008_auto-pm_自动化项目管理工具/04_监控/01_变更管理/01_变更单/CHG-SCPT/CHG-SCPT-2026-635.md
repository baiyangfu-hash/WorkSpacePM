## 4. 变更原因

**变更背景**：
PLC 标准模板：按实例清单生成工位背景 DB，结构体/FB/DB 同目录，独占结构体带所属 FB 编号。共 43 项（45 个路径，第 41、43 项各两个文件），清单原样照共享库 plans/PLC模板_多实例背景DB与同目录_文件清单草稿_20261111.md（冻结版，sha256 90b972cb54159c67cce41ac25f5ea10957c9a4eb3b4e5feb2aee538818cc3eac）。要点：⓪copier.yml 加 station_instances、校验，以及 8 个隐藏变量 db_slot_1～db_slot_8；①project create 加可重复参数 --station（最多 8 个，英文字母开头、字母数字组成，不写只有 Station1），传 copier 变量 station_instances，只在 --stack plc 时传；②一个背景 DB 一个文件：工位 FB 文件夹放 8 个槽位文件，文件名只写 {{ db_slot_N }}.jinja（N=1～8），判断写在 copier.yml 的隐藏变量里：db_slot_1 固定为 DB_1001_<第1个名字>.scl，db_slot_N（N≥2）在清单够长时为 DB_1001_<第N个名字>.scl、否则为空，空名文件 copier 跳过，DB 内容只写一份放 template/ 外的 _includes 公共片段；③GlobalVars 和 OB123 按清单循环；④块名 FB_1001_Station1 不改，工位内多重实例只写进使用说明和接口文档（905 §4.11-1），FB 源码不加示范实例；⑤3 个背景 DB 从 00_全局数据/ 挪进各自 FB 文件夹（第 3、12、14 项删除旧路径），GlobalVars 留在 00_全局数据/；⑥程序架构文档写导入顺序（结构体→FB→DB，GlobalVars 在所有结构体后，OB 最后）；⑦独占结构体改名 ST_1001_Station1、ST_3001_ExternalDevice（嵌套 ST_3001_UpstreamDocking/ST_3001_DownstreamDocking）、ST_2001_CommonAlarm（第 31、33、35 项删除旧名），ST_ServoAxis 不动（归伺服单 D-245）；⑧generator.py 产出 ST_<FB编号>_<工位名>。测试只改路径、加断言，不放松任何断言。删除路径核实：工位分支提交＋pm pr open 能带删除（先例 6da80cb0 CHG-SCPT-2026-626、134ea4aa）；收口并回控制根（candidate_merge_back_service）不替用户删文件，遇删除会整单拒写，所以收口前先让控制根同步含本单的 main。前提：#745（632）与 #747（633）先合并，本单在 main 上开；规则依据 905 修订单先批或同批。安全回路：否。 槽位文件名写法（冻结版）：不把判断写进文件名，因为那样文件名 97 个字符，放到本机控制根下完整路径约 271 个字符，超过 Windows 默认 260 上限；改为 {{ db_slot_N }}.jinja 后文件名 21 个字符。云端实测（P1，15:45Z，copier 9.19.1）：不填清单出 1 个，3 个工位出 3 个，8 个工位出 8 个，公共片段目录不进生成项目。本机实算（2026-11-11）：本单 45 个路径放进控制根 C:/Users/fubai/Documents/My_Workspace/ 后最长 222 个字符，放进工位目录 .auto-pm/worktrees/claude-xxxxxx/ 后最长 255 个字符（最长的是 01_外部设备交互/PRD/接口文档_IFC-FB3001-ExternalInteraction.md.jinja，不是槽位文件；槽位文件 197/230）；本机 git core.longpaths=true、系统 LongPathsEnabled=1。Windows 上 copier 渲染未实测，在实施 PR 的 gate-full 里补验。

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

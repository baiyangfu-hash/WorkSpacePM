## 4. 变更原因

**变更背景**：

A6-R 已将中文 Python 项目名、默认目录和 PLC 初始 Spec Snapshot 的创建器缺陷合并到研发母体。为验证该修复在真实工作区拓扑而非仅临时测试目录中可复现，需要创建两个独立、可追溯的测试项目。

**变更必要性**：

已存在的靶子项目 SW-2026-009、DJ-2026-005 和原 A6 隔离证据 DJ-2026-010 均不重用、不覆盖。预检确认 SW-2026-010 未占用，因此 Python 测试资产使用该编号；PLC 使用未占用的 DJ-2026-011，避免与原始证据冲突。

**参考依据**：

用户已明确批准 A6（含 Python/PLC 测试资产）开工，并要求在 A6-R 源头修复完成后继续 A6；研发母体提交 4f119d7c；A6-R 变更单 CHG-SCPT-2026-211。

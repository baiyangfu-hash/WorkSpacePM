## 1. 根因与变更方案

1. 根因：
   - `git_hook.py` 生成的 `commit-msg` 钩子白名单只认 `COMMIT_EDITMSG`，在 linked worktree 执行合并时因路径为 `MERGE_MSG`/`SQUASH_MSG` 而误拒（#4）；
   - `pm_merge.py` 的 `archive-changes` 对存量 815 张变更单逐文件起 `git cat-file blob` 子进程且未禁用 `core.fsmonitor`，干跑耗时超 70 秒，且 `change transition --to completed` 缺少归档指引（#5/#7）；
   - `git_hook_enforcer.py` 与 `pm_merge.py` 仅拦删除变更单，未拦截短名分支修改已 `completed`/`closed` 变更单正文（#6）；
   - `pre-commit` 未执行跨工位属主会话互锁也未记录工位操作日志，看板无法告警非主人操作（#3）；
   - 提交钩子与 `doc check --project` 缺少 UTF-8 BOM 与裸 CR 换行符校验（#14）；
   - `release_deploy_check.py` 未在切换指针前校验账本中残留的未关闭 `WORK-DEPLOY-*`/`RUN-DEPLOY-*` 冲突，且 `release_deploy`/`release_wiring` 成功后不回收干净的临时 `deploy-<id>` 分离工位。
2. 方案（按已批准的 `CHG-SCPT-2026-750` §5.2 与 §7）：
   - `auto_pm/ui/cli/git_hook.py`：在 `commit-msg` 钩子白名单中放行主仓与 linked worktree 的 `COMMIT_EDITMSG`、`MERGE_MSG`、`SQUASH_MSG`；
   - `scripts/pm_merge.py` 与 `auto_pm/ui/cli/change.py`：`Git.run` 与 `_git_blob` 禁用 `core.fsmonitor`，`_collect_archive_plan` 改为单次 `git ls-tree -r -z` + 纯 Python Git blob SHA-1 比对 + 批量 `git cat-file --batch`，`change transition --to completed` 成功后打印归档提示；
   - `auto_pm/infrastructure/git_hook_enforcer.py` 与 `scripts/pm_merge.py`：将修改已 `completed`/`closed` 变更单划入受保护范围（短名分支拒绝，不误伤首次归档新增）；
   - `auto_pm/infrastructure/git_hook_enforcer.py` 与 `scripts/cockpit_board/stations.py`：在 `pre-commit` 落地跨工位属主会话互锁（用户无 agent 标记终端放行并留痕）并追加 `.auto-pm/logs/station-ops.jsonl`，看板工位页展示最近操作者≠主人告警；
   - `auto_pm/infrastructure/git_hook_enforcer.py`、`auto_pm/domain/doc/link_check.py` 与 `auto_pm/ui/cli/doc.py`：`pre-commit` 拒绝暂存含 UTF-8 BOM 或裸 CR 的治理/记录文件，`doc check --project` 检出并报告 BOM/裸 CR；
   - `auto_pm/application/core/{release_deploy_check,release_deploy,release_ledger,release_wiring}.py`：`preflight` 只读检查账本残留活跃 `WORK-DEPLOY-*`/`RUN-DEPLOY-*` 冲突，发版成功 `close_books` 与 `write_receipt` 完成后尽力回收干净的临时分离 `deploy-<id>` 工位。

## 3. 验收

- 主仓与 linked worktree 的 `MERGE_MSG`/`SQUASH_MSG` 通过 `commit-msg` 钩子，目录外路径仍拒；
- `archive-changes` 改为批量 `ls-tree` + SHA-1 比对 + `cat-file --batch` 并禁用 fsmonitor，`change transition --to completed` 输出归档命令提示；
- 短名分支修改已 `completed`/`closed` 变更单在提交钩子与 `pm_merge` 均被拦截，首次归档新增与合法正式变更单不受误伤；
- 异会话 agent 在别人工位提交被 `pre-commit` 物理阻断并记录 `.auto-pm/logs/station-ops.jsonl`，持有人/借用者/用户无标记终端放行，看板展示异会话操作告警；
- 暂存带 UTF-8 BOM 或裸 CR 的治理/记录文件被 `pre-commit` 拒绝，`doc check --project` 报告 BOM/裸 CR 并退出 1，正常 UTF-8 全绿；
- `release preflight` 在存在未关闭残留 `WORK-DEPLOY-*`/`RUN-DEPLOY-*` 冲突时拒绝发版；发版成功后尽力回收干净的临时分离 `deploy-<id>` 工位；
- `ruff`、`mypy`、`role check`、`doc check`、相关 pytest、`implementation-card precheck` 全绿，云端 L3 门禁 `passed`，AUD-001 独立审计 `PASS` 并登记，`git diff --name-only` 全部落在可改范围。

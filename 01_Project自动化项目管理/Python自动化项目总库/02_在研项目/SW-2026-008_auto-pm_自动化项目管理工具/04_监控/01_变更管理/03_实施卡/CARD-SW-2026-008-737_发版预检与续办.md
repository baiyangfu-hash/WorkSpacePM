## 3. 验收

- 沿用同一个发布单、Decision 和构建。完整候选 SHA、原现役版本、原回退记录、指针、批准路径、逐文件、全量判决或独立审计任一不匹配时拒绝。
- 并发部署由本机文件锁串行；拿锁后复查活动版本和候选。仍按原确认规则，回退的确认引用不可重用。
- 续办前核对并续期原发布 Run 的租约。租约过期或持有人变化时，保持指针原样，并报告需恢复原 Run。
- 真部署在建账和切换前先干跑 Git 钩子，切换后再跑一次。暂存区非空、钩子缺失或报错均停止。
- 现役 CLI 缺少续办支持时，从控制根执行同一发布逻辑，核对真实运行身份。待发布文件阻止修复先合并时，工位入口核对批准范围、精确独立审计和驾驶舱合并门禁。受保护范围仍要求对应的托管全量。用 736 验证一张回执、同一个发布单和准确的现役版本。

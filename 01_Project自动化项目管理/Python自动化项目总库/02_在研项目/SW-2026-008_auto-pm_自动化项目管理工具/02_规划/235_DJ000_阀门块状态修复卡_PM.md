本卡只给 `main.py pr open` 提供“可改范围”，由云端会话起草，不改任何代码。该 PR 改的是 DJ-2026-000 的 PLC 程序，000 没有单独标定安全区，和 009 一样按安全区处理：PR 必须写“安全回路: 是”，并等用户在 PR 上写“安全签字 <头提交号>”，agent 不自己签字。

背景：DJ-2026-000 的 FB_ValveControl 里 `ValveState` 在 VAR_OUTPUT 和 VAR 里同名重复声明，块内 `#ValveState` 到底指哪个取决于编译器；另外块内 4 处读自己的 VAR_OUTPUT（TIA V19 实测同类写法会报“参数无法初始化”）。该修复已由笔记本按变更单 CHG-PLC-2026-006 做在工位里。

改法：内部状态改名 `s_iValveState`（VAR 里那个），块内所有 `#ValveState` 引用改用它；输出 `ValveState` 只在 `IF #FaultLocked THEN` 的提前 RETURN 前和块末尾赋值，行为与原意一致。不换定时器类型，不改其他块。

|---|---|---|
| `0100_PLC自动化/DJ-2026-000/FB100/FB_ValveControl.scl` | 存在 | 内部状态改名 `s_iValveState`，消除与 VAR_OUTPUT 同名重复声明，输出只在提前返回处和块末尾赋值 |

## 根因与全库同类排查（FIX-001）

- **根因**：[pm_merge.py](../scripts/pm_merge.py) 原版（卡 311 `97190e2b`）第 384 行 `_control_root_copies()` 将分支全部变更路径 `*paths` 一次展开传给 `git status --porcelain=v1 -z --untracked-files=all -- *paths`。卡 316 共 623 个路径，命令行总长度超 5 万字符，超过 Windows `CreateProcess` 的 32,767 字符上限，导致 `[WinError 206]`。
- **全文件同类排查**：遍历 `pm_merge.py` 全文 `*` 展开传参调用，仅第 384 行一处将完整路径列表展开进 `git` 命令行。

## 改成什么

1. `SW8/scripts/pm_merge.py`：
   - 新增 `STATUS_BATCH_CHARS = 8000` 与 `_chunk_paths(paths, max_chars=None)`，按命令行字符总长安全分批；
   - `_control_root_copies()` 按批次循环执行 `git status --porcelain=v1 -z --untracked-files=all -- *batch`，语义与原版完全等价，永不超 Windows 命令行上限。

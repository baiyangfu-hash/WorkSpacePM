1. **为什么**：WBS D02“实现可复现构建入口”——固定 Git 输入构建载荷，拒绝 dirty 或缺失依赖；同输入两次清单相同；此源码在 D03 冻结前完成并验收。今天的发布构建靠一个不在仓库里、没有测试的 shell 脚本（`.auto-pm/reports/dep1_release_ops.sh build`）：`git archive <提交>:<项目根> auto_pm templates` → bsdtar 解包 → `release_meta.json`（`built_at` 取提交时间）→ 逐文件 SHA-256 清单。本卡把它产品化。
2. **做什么**（新增 2 个文件，不改任何已有文件；见 §4）：
   - `scripts/pmf_build.py`：`build`（`resolve_commit`、`project_version`、`export_payload`、`check_required`、`unresolved_imports`、`release_meta`）与 `verify`；命令行 `build` / `verify`，退出码 0 成功、2 被拒绝（原因为稳定的机器可读代码）、3 输入错误；
   - **只从已提交的 Git 对象构建**：输入不是提交对象（含不存在）拒绝；工作树 dirty 或有未跟踪文件不影响结果；

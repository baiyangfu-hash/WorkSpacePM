改成什么：

1. 全流程、标准线的授权凭据是：用户批准过的变更单、领卡占位、PR（CI 全绿加独立审计）、验收后由用户推到完成。不再要求每次改动都有 Work/Run/租约。
2. Work/Run/租约只在两种情况下要：
   - 看板“确认开工”一键流，由驾驶舱自己建，agent 不手工建；
   - 命令本身要求 Run 或租约的，例如 `pm verify`。
3. 变更单被用户批准之前（快线除外），agent 只做三件事：跑只读命令、建变更单、领卡占位。不改文件。
4. 新增 PR 线收口流程：`pm_flows.py closeout-pr <项目编号> --chg <变更单号>`。原来的“交卷到收口”保留，给走 Run 的卡用。

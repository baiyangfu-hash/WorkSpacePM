## 怎么调用

```bash
python main.py -w <工作区根> <命令组> <子命令> [参数]   # 控制根里，工作区根默认是当前目录
python main.py --control-root <控制根> ...             # 候选/工位执行时必须显式指定
python main.py --version
python main.py <命令组> --help
```

- 日常和 AGENTS.md 一样写 `main.py`；装了入口脚本的环境里 `auto-pm` 与它等价。
- `-w`、`--control-root` 必须放在子命令之前。
- 驾驶舱命令只在控制根执行；在工位里执行会被拒（见 AGENTS.md「多 agent 工位与控制根规则 (WS-001)」）。
- 没有已授权的 Work、Run 与有效租约之前，只用只读命令（说明里带「只读」的）。
- 说明里带「用户本人」的命令，agent 不得代填凭据或口令。

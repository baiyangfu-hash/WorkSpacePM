# M2 入口分类、定位、交接与薄入口——需求说明

> 版本：V1.0（2026-10-06，随卡 055 / M2-GOV-TD2 批准生效；生效前只是提案）
> 性质：需求文字，不宣称任何功能已实现；功能的交付与验收以各实施卡的门禁为准。
> 来源：需求草案 v0.3（原样归档，见 `02_规划/archive/F05_与审计讨论_20261005/`）、F05 的裁决记录与审计报告（同目录归档）。
> 与实现的关系：本文是 V05 系列卡与以后各期卡的需求来源；与归档的旧草案冲突时，以本文与总计划、最终决定为准。

## N1 接诊、分诊与当前焦点

用户以自然语言提交需求或问题，PM 先查代码、台账、WBS、收件箱，再给出专业分类、证据、重复检查、影响、备选处置、成本风险和需要用户决定的点。机器缺少取证摘要即拒绝入单；内容真实性由明确实现的证据校验范围与审计共同承担，不能把格式合法称为事实真实。用户有最终决定权，系统建议不得直接改变焦点或执行权限。

类别为 iteration、bug、change、urgent、debt。change 使用 add/modify/reduce/freeze/remove，其他类别不得携带 change action；分类对应 OPT/DEF/REQ/EMRG/OPT，Work 类型按批准映射。领域和范围由实际上下文及显式输入校验，不静默丢弃冲突输入。旧未分类 SDK 请求的兼容行为由第 1 期缺陷修复卡（卡 054）明确，不擅自删掉已批准的兼容路径。

分诊采用产品型 PM 接诊模型，urgent、阻塞 bug 等可作为建议依据，不执行固定表的自动抢占。紧急建议应有设备或人身安全、数据损坏或丢失、阻塞全部后续工作、错误产出的客观证据。入箱不改当前 Work、Run、lease 与 owned paths。

### N1.4 挂起、恢复与分期

M2 只提供真实的、带版本和能力标志的 resume/orient 共用只读查询合同。`parking_supported=false`、`preemption_supported=false`；挂起与抢占相关动作显式返回 UNSUPPORTED，查询不能成为执行授权。“无焦点”“未支持”“读取失败”必须区分，不能用空列表暗示已支持挂起。

完整挂起放 M3：调度状态与业务状态分离，每个项目一个当前槽、最多三个挂起槽；恢复时重新核验授权与资源。不能把普通 BLOCKED 从唯一 Mission 约束中排除来假装实现 PARKED。运行中插队还须 V04-R1 的回收与 fencing 证据。M2 遇紧急事项按现有授权先收口或取消后重新规划，不称为挂起。**N1.4 的完整目标保持未交付。**

### N1.5 定位查询

resume 与 orient 共用一份版本化投影：控制根与执行根及候选身份、configured 与 effective runtime、焦点和下一步合法动作、卡、WBS 与检查点引用、收件箱摘要、冲突与能力标志。真实 GUI 与 CLI 消费该合同；缺失或不兼容的版本失败关闭。快照不携带租约口令或接手码，不创建表、不初始化库、不改焦点。

## N2 一键换 Agent

目标是先只读定位再领取，或先领取再回显定位，两种次序皆可；一次性、短效、绑定 Run 与工作树的接手码只保存哈希。口令不得上命令行、历史或明文持久化；TD-SW008-064、065 为前置。旧 owner 写入被围栏拒绝不等于旧 OS 进程退出，未知的回收状态必须保留。

V03 已验收的底层 handoff.v2 机制不等于此用户流程已交付。不同 IDE 的真实接手、当前控制根与候选身份、旧 owner 拒写及进程处置需要独立验收。M2 的 orient 查询不顺便实现 claim，也不自动启动所有模型或 Agent。

## N3 薄入口

各 IDE 的薄入口只调用真实的 pm 命令、依据结果处理、把新事入箱；单一模板生成并校验命令和链接。不复活已退役的技能。各 IDE 的安装与 `.trae` 修改须明确批准，用户尚未授权的路径不因本需求文档而获得执行权。

## 分期与验收

| 阶段 | 内容 | 证明要求 |
|---|---|---|
| 第 1 期及其修复 | 分类、收件箱、分诊记录校验、plan 分类、只读建议；修 A-P1-01～03、C11、C12 | 旧批准历史与新修复结果分列，按最终提交审计 |
| M2 / V05-A | 版本化共用查询，resume、orient、SDK 真消费者 | 独立合同卡与验收；能力标志为 false、动作为 UNSUPPORTED |
| M2 / V05-B | GUI 双根、对 A 的查询消费、生产线程池与构造接线 | 独立接线卡；不等于双领域全链已验收 |
| M2 / V05-C | 真实双领域 GUI、真实模型进程、权限与收尾 | A、B 与 F01-a 通过后独立联验；调用真实模型前先获用户授权 |
| M3 挂起 | 当前槽与挂起槽、安全恢复、迁移屏障 | 运行中插队依赖 V04-R1；一致备份与维护窗口；不能用旧发布回滚新事实库 |
| N2 | 一次性接手码、口令安全、产品层交接 | TD-SW008-064、065 与恢复边界，真实两个 Agent |
| N3 | IDE 入口生成与安装 | 命令稳定后逐个授权，链接与命令校验 |

模型、适配器、执行者标识与授权分别表达，不因模型名字可以填写就声称自动支持（TD-SW008-084）。

WBS 修订 6（SYS-2026-001 侧）是独立的卡，须先于 V05-A 完成；F01-a 只做“标记消失即失败关闭”（HEAD 有标记而暂存区或工作区没有就拒绝，全部改名与移动都拒绝），不新增登记；合法移动与退役归 F01-b 另卡。各产品卡产品文件一般不超过约 6 个、围绕一组关键反例，超出继续拆。`codex` 命令与版本存在不证明认证或真实执行可用。正式需求验收不能只靠本文的文字。

## 6. 真源与执行边界

主工作区、隔离候选、部署目录和实际运行身份是四层事实。K13 只证明读取到的 active 指针；本轮未校验 previous、manifest 的完整发布链、实际进程路径或 canonical continuity.db 当前绑定。下次实施先依据正式基线定位并核 schema，再按授权只读核治理记录；不得手写库修正不一致。

授权身份、owner/lease、epoch/CAS、隔离和 owned paths、幂等、handoff、Checkpoint、门禁及人类验收等公共合同不能以“外部 Agent 执行”名义取消。任何凭据必须由合法通道取得，不能放入简报或跨会话复制。

同一操作系统用户拥有任意写权限时，提示词和普通 Git hook 并不能物理阻止所有路径的直接写入。本包只要求在真实受控通道和正式核验/合并/发布边界证明权限与证据有效；若要求强制隔离任意外部进程，需要明确 OS/权限/沙箱设计与实测，不能由规则文档宣称已经实现。

### 7.2 授权成立与失效规则

1. 用户在 GUI 或受控审批脚本中明确点击/执行“批准实施”后，系统才可把 `PENDING` 判定为 `APPROVED`；聊天文字只能作为审批证据来源，不得由 Agent 自行转换为 `fubai` 的签名。
2. Approval Receipt 必须绑定本卡完整字节哈希。卡片任一字节在签字后发生变化，旧 Receipt 与 Decision 自动失效，禁止继续创建 Work/Run。
3. 执行批准与最终验收是两个独立签字门：实施批准只允许启动 §8；最终验收必须在 G1～G5、Checkpoint、Run/Work 和台账证据齐备后由用户单独确认。
4. Agent 可以准备审批载体和执行命令，但不得代替用户署名，不得把命令执行者与审批决策人混为一谈。

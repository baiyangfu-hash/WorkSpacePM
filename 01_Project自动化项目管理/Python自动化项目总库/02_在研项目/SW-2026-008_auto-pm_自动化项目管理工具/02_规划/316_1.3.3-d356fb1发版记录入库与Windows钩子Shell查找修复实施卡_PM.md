## 根因与全库同类排查（FIX-001）

- **根因**：`release_wiring.py` 第 283 行 `hook_dry_run()` 硬编码 `execute(["sh", ".git/hooks/pre-commit"], Path(root))`。Windows 默认 PowerShell 的 `PATH` 仅包含 `C:\Program Files\Git\cmd`（不含 `usr\bin`），导致 `subprocess.run(["sh", ...])` 报 `[WinError 2] 系统找不到指定的文件。`，使 `release ship` 切后自检失败触发回退。
- **全库同类排查**：对 `SW8/auto_pm/**/*.py` 全量 AST 扫描命令列表首元素为 `"sh"` 或 `"bash"` 的全部调用，**全包仅有 `application/core/release_wiring.py:283` 一处**，已一并修复。查找严格通过 `auto_pm.infrastructure.executable_lookup.find_on_path`（不调用 `shutil.which`，遵守 `test_executable_lookup.py` 守卫）。

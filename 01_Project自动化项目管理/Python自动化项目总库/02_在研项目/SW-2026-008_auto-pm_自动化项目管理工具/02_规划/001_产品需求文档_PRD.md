# 产品需求文档 (PRD) - auto-pm 自动化项目管理工具

> **2026-11-04 提示**：本文主体写于 2026 年 8 月，不描述后来的 Continuity v2 账本、工位、租约、发布快照等架构；现状以 `ARCHITECTURE.md`（V3.0.0）为准。

## 1. 产品背景与愿景
在非标自动化与工业全栈研发场景中，项目资产高度异构（PLC 梯形图/SCL、HMI 画面、Python 上位机、硬件点表与图纸），传统的通用项目管理软件无法理解工业控制语义。
`auto-pm` 旨在构建工业自动化领域的**单一真源管理驾驶舱**，实现从异构逆向摄取、53 项门禁治理、SCL 静态合规检查、变更单全生命周期流转到 AI 双模协同的工业级基础设施。

## 2. 核心功能需求矩阵

| 需求编号 | 功能模块 | 优先级 | 需求描述与验收指标 |
|:---|:---|:---:|:---|
| **REQ-PLC-001** | PLC 53 项门禁扫描 | P0 | 支持扫描项目结构、PRD 四件套、SCL 语法合规性、快照一致性，提供 0 Fail 阻断机制 |
| **REQ-PLC-002** | 异构变量表逆向管道 | P0 | 自动探测 AutoShop、GX Works3、CodeSys、Excel 14 种格式，统一转译为标准点表 |
| **REQ-SPEC-001**| 全局规范治理引擎 | P0 | 维护 `spec_registry.json`，一键编译生成全库 `00_INDEX` 与各域 `README.md` |
| **REQ-SPEC-002**| STD-820 外部交握协议 | P0 | 内置上下游 8 步闭环握手与 4s ON / 4s OFF 心跳检测协议模板与状态机 |
| **REQ-CHG-001** | 变更管理与台账对账 | P0 | 12 章节标准变更单生成，支持 LOCAL/MODULE/SYSTEM/SAFE 影响评估与台账自动化双向对账 |
| **REQ-GUI-001** | 现代化工业深色驾驶舱 | P1 | PyQt6/QML 架构，支持业务大厅、项目工作台、规范中心、变量表映射 7 大功能面板 |
| **REQ-AI-001**  | AI 协同总线 | P1 | 通过 `.auto-pm/ai_context.json` 与 `.auto-pm/ai_feedback.json` 实现无缝人机协作 |

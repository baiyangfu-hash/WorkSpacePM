## 根因与设计要点

1. **单机轻轨交接无数据表规范**：原 `PM-056 V1.0.0` 仅规范重轨 `Work/Run/Checkpoint/Lease`，而单机日常迭代不走 Run 也不靠 GitHub 远程 `claims/*`，缺少固定字段、长度上限、防漂移与失败关闭协议。
2. **跨项目目录零冲突**：经盘点 `SW-2026-008/04_监控/` 已有 `03_M7_真实试用`，而 PLC 项目 `DJ-2026-005/` 无 `04_监控/`（监控目录为 `11_监控/`），因此采用无编号子目录 `交接交换区/`（Python/治理类在 `04_监控/交接交换区/`，PLC 项目在 `11_监控/交接交换区/`）。
3. **单机模式 `plan_status.py` 与 `pm_flows.py` 降噪**：两脚本原逻辑写于 GitHub 按需三档改造之前，默认联网 `git fetch` 并读取远程 `claims/*`；现统一对齐 `pm_merge.py` 的 `github_mode.json`（默认 `备份` 档）。

## 4. 变更原因

**变更背景**：
P1 Runtime Recovery：标准入口 python main.py --resolve-only 因 active/previous release 槽位含未登记 .ruff_cache 而 Exit 4；同时存在受 ACL 保护的历史 release 路径，禁止以 Git 表观删除直接清理。

**变更必要性**：
恢复双槽 manifest 校验与标准启动入口；将静态检查缓存从不可变 release 槽位隔离，且不触碰当前无关 dirty 文件、项目源码或 P2-P7 架构工作。

**参考依据**：
P1 架构评估结论；active_release.json；launcher/launch.py；用户于本会话明确批准 P1 开工

## 12. 附录

### 12.1 填写指南

#### 如何选择技术领域?
- 主要改哪个专业的交付物,就选哪个领域
- 如果同时涉及多个专业,选**最主要**的那个作为主领域,其他在§6.2中标注

#### 如何判断影响范围?
- **LOCAL**: 改一个变量/一行代码/一个接线端子
- **MODULE**: 改一个FB/一条输送线/一台设备
- **SYSTEM**: 改全局变量/联锁逻辑/通讯接口
- **CROSS**: 改了电气,PLC和HMI都要跟着改
- **SAFE**: 动了急停回路/安全继电器/SIL相关

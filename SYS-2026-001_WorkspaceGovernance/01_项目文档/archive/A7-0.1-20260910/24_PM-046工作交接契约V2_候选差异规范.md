# PM-046 工作交接契约 V2（候选差异方案）

**状态**：候选，现有 handoff.v1 继续有效；未修改正式 PM-046。
**变更单**：CHG-SPEC-2026-014；**上位候选**：文档 20。

## 1. V2 最小字段

| 字段组 | 必填内容 |
|---|---|
| 身份 | `schema_version`、`handoff_id`、`subject_project_id`、`control_project_id`（可空）、`work_id`、`run_id`、`checkpoint_id`（按阶段可空） |
| 路径与运行 | `development_root`、`runtime_root`、`release_id`、Adapter/capability |
| 基线 | source/target Git revision、dirty-tree 声明、允许路径或 worktree 标识 |
| 责任 | from/to role、owner、lease、过期处理、回收规则 |
| 输入与结果 | `read_first`、已批准 CHG/决策、限制条件、验收项、evidence、result/closure 引用 |

每一字段必须结构化校验。PM_SESSION 只可作为 `read_first` 的项目摘要来源，不能是唯一身份字段。

## 2. 状态与兼容

沿用已存在的派发、接受、heartbeat、结果提交和关闭能力；V2 在 v1 外包一层字段校验及 capability 协商。旧 handoff 可读取为 v1，但当新场景要求 work/run/lease 或基线防护而其缺失时必须拒绝执行，不得静默降级。

## 3. 豁免和禁止项

豁免必须同时记录 decision/CHG ID、审批者、范围、到期时间和证据；源码 suppression 标签、自由文本回执或 AI 自称完成均不足以豁免。Adapter 不得持有 Work 真源或越权写 PM_SESSION；结果提交不得在租约失效或 Git 基线冲突时成功。

## 4. Dogfood 验收

验证正常交接、重放恢复、过期 lease、dirty tree、基线漂移、schema 不兼容和篡改 read_set 七类场景。每个失败场景必须返回机器可读原因，并保持真源不被部分写入。

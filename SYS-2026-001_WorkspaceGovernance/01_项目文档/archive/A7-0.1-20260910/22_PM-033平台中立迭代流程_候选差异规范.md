# PM-033 平台中立功能模块迭代流程（候选差异方案）

**状态**：候选，未修改正式 PM-033。
**变更单**：CHG-SPEC-2026-012；**上位候选**：文档 20。

## 1. 修订目标

PM-033 的迭代生命周期保留，但其 Trae 范围、`.trae/specs` 路径和 `python -m auto_pm` 字面命令应被替换为平台中立的语义入口。它只协调需求到验收，不持有连续性核心状态。

## 2. 拟定规则

1. 生命周期为：探路 → 计划与 CHG 授权 → Work 派发 → Run 执行与 Checkpoint → 验证 → PM 收尾；每一步引用连续性对象，不重定义其字段。
2. 规范、需求、实现和证据以“已解析项目根下的受控路径”描述；不得将任一 IDE 的隐藏目录作为必经真源。
3. 命令以 `AUTO_PM_ENTRY` 表示已验证的驾驶舱入口。各 Adapter 可将其映射为根 `main.py`、发布 launcher 或开发入口，但必须输出运行槽位与版本证据。
4. `.trae`、`.cursor`、`.agent` 和 `AGENTS.md` 是 Adapter/引用层：可提供入口说明，不得各自存放 Project、Work、Run 或 Checkpoint 真源。
5. 任何适配器不支持某 capability 时应显式拒绝或降级为只读，不得伪造完成。

## 3. 发布前验收

在发布候选规范前，需在至少两个 Adapter 入口完成同一 Work 的 resolve、handoff、resume 和验证，且生成的 `subject_project_id`、基线、证据集合一致。此要求不等于立即改写任一 Adapter。

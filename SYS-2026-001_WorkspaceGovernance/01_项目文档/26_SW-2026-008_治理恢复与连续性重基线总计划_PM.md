每包必须独立包含：目标与非目标、事实读取集、owner、精确路径上限、前置状态、授权证据、实现/文档差异、测试与门禁、回退方式、产物状态分层、下一合法动作。上一包验收不自动批准下一包。

只有同时满足以下条件，User 才可决定恢复、替换或废弃该技能：

1. G2 的平台中立契约已获批准；
2. G5/G6 的 Work、Run、Checkpoint 和 Handoff V2 已通过迁移与故障注入验证；
3. PM_SESSION 已降为项目投影，控制面不再覆盖 subject state；
4. CLI、API 与所有 Agent adapter 对同一事实给出一致结果；
5. 母体、inactive release、切流后 runtime 三层证据可区分且可回退；
6. 至少两种独立 Agent 会话完成真实冷启动 Dogfood；
7. User 明示解除 `QUARANTINED`。

在此之前，任何“临时恢复一下 PM 技能完成落账”的做法都视为治理旁路。

# 使用说明 FB_2001_CommonAlarm_AllStation

## 1. 功能

公共报警汇总。接收三工站+系统级所有报警BOOL信号，计算最高优先级报警码，管理MES去重队列(10条)，控制5路指示灯/蜂鸣器。

## 2. 报警码选择策略

- 仅当有新报警(之前码=0,当前≠0)时才触发蜂鸣器脉冲
- 同时多报警时，取最高优先级的报警码（表在IFC§4中）
- 报警队列自动去重：同一码在队列中已存在则不重复入队

## 3. 指示灯逻辑

| 灯 | 条件 |
|----|------|
| 绿灯 | NOT q_wGlobalAlarmWord.0 AND 自动运行中 |
| 红灯 | q_wGlobalAlarmWord <> 16#0000 |
| 黄灯 | 暂停OR等待OR回原点中 |
| 蜂鸣器 | q_bNewAlarmPulse (1s ON/OFF脉冲) |
| 复位灯 | q_wGlobalAlarmWord.0 (无报警=ON，反馈复位状态) |

## 4. 复位策略

- 收到 i_bReset 时清除全部报警码和队列
- 硬件故障消失后（故障BOOL回落），报警码自动回到0

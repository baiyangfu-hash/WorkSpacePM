## 转换只有这 4 条

1. 去掉 `BEGIN` 一行和末尾的 `END_FUNCTION_BLOCK` / `END_FUNCTION`。
2. 去掉变量前的 `#`（`16#FF`、`T#5S` 这类常量不动）。
3. FB_1001 的 `CONST … END_CONST` 改成 `VAR CONSTANT … END_VAR`。
4. OB1 改成 PLC_PRG。OB1 里 5 行 `GlobalVars.xxx := GlobalVars.fbXxx.io_xxx;`（把 VAR_IN_OUT 读回来）在包里注释掉了：CODESYS 的 VAR_IN_OUT 按引用传，块里改的就是全局变量本身，这几行多余，而且 CODESYS 不许从块外面读 VAR_IN_OUT。**这一条是现场程序也要改的地方**，AI 会另记一条。

## 一、粘贴（约 30 分钟）

| 16～33 | **POU**，语言 ST。`FC_3003` 选“函数”、返回类型 `WORD`；其余选“功能块” | 文件名里 `_声明` 前面那段，如 `FB_TON` | 上半区（声明）全删，粘 `_声明`；下半区（实现）粘 `_实现` |

## 二、编译

菜单 **编译 → 生成**（F11）。下方“消息”窗口要 **0 个错误**，警告可以有。

有错误就截图“消息”窗口发讨论串，**不要自己改程序**（改了就不是要签的那份）。最可能报的是 `sUpId[2 * iReg]` 这种字符串取字节的写法；它和现场 FB_3002 是同一写法，报了就说明现场程序也要改，正好查出来。

## 三、仿真起步

1. 菜单 **在线 → 仿真**，打勾；再点 **在线 → 登录**（Alt+F8）→ 提示下载点“是”→ **调试 → 启动**（F5）。
2. 改变量值：打开 GVL 或 PLC_PRG，在“准备值”列填值，按 **Ctrl+F7 写入**（一次性）或 **F7 强制**（一直保持）。`ESTOP_OK` 带硬件地址，要用 F7 强制。
3. **让机器能动**（多数条目从这里开始），依次设：

| 变量 | 值 |
|---|---|
| `GVL_SafetyIO.SAFETY_FAULT` | FALSE |
| `GVL_SafetyIO.ESTOP_OK` | TRUE（F7 强制） |
| `GVL_SafetyIO.FIELDBUS_OK` | TRUE |
| `GVL_SafetyIO.DOOR1_LOCKED` ～ `DOOR8_LOCKED` | 全部 TRUE |
| `GlobalVars.bModbusEnable`、`bModbusUpLinkOK`、`bModbusDownLinkOK` | TRUE |
| `GlobalVars.stStation1.stControl.bAutoEnable` | TRUE |
| `GlobalVars.stStation1.stActuators.stCyl1.stSts.IsRetracted`、`stCyl2.stSts.IsRetracted` | TRUE（F7 强制；气缸块卡 005 才接，不强制工位走不动、门也解不了锁） |
| `RESET_BTN` 写 TRUE 再写 FALSE；**等满 10 s**；再写 TRUE、FALSE；`START_BTN` 写 TRUE 再写 FALSE | |

看到 `GlobalVars.fbSafety.q_iState = 4`、`q_bSafeToRun = TRUE` 就是能动了（0 回路断开、1 等满 10 s、2 等运行复位、3 等启动）。

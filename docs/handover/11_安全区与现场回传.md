# 安全区与现场回传

> 出处：用户已定事项（项目记忆，2026-10-21～10-22）；设计稿 `现场回传与安全签字规则`、`电气自动化安全规范`（共享文件夹，**不在仓库里，待搬**）；仓库里的 `reviews/安全区签字检查_说明.md`。写法为要点，细节以原稿为准；与原稿不一致时以用户原话为准。

## 一、什么算安全区

急停、安全门及门锁、光栅、联锁（**包括只靠软件的防撞联锁**，如机器人与气缸的干涉区、两轴防撞）、安全继电器、双手启动。**未标定过安全区的项目，任何 PLC 改动都按安全区处理。**

## 二、改安全区的流程

1. AI 改动 → 2. **先仿真**（AI 写用例单，用户跑 PLCSIM / InoProShop 仿真 / GX Simulator3 / 测试台）→ 3. 用户在 PR 评论里单独写一行 `安全签字 <提交号>` → 4. 才能合并。
2. 签字只认用户本人的 GitHub 账号（登录名加数字 ID）对**当前头提交号**的评论；推了新提交就作废，要重签；审计不能代签。
3. PR 描述必须有单独一行 `安全回路: 是` 或 `安全回路: 否`；改 `0100_PLC自动化/` 下任何文件却没写，`gate` 不通过；填“否”却碰到安全区，也要签字。
4. `OR TRUE` 之类旁路、安全点漏接的，机器直接判不合格，不能靠签字放行。
5. 检查器：`reviews/tools/safety_zone_check.py`，由工作流 `safety-gate` 回报提交状态 `safety-zone`，是 main 的必过检查。标法：清单文件 `safety_zone.yml` 加源码里的 `// @安全区 开始 … 结束` 区段注释，取并集；`io_points.csv` 加“安全”列。
6. 已知漏洞：拿着用户账号令牌的 AI 能代发评论，机器分不出。补法见 `01_角色分工与流水线.md` 第五节。

## 三、用户惯用的电气安全做法（新项目默认按这个来）

下面是用户在美国康宁现场用的做法，**写新项目的急停、复位、门锁逻辑时默认照此**；客户有要求另定的，写进项目需求，不要擅自改默认。

| 项目 | 默认做法 |
|---|---|
| 急停复位 | 同一个复位按钮按两次：第一次复位安全继电器（安全电路自判）；第二次复位运行系统，且要求安全继电器触点反馈正常、距第一次已满 10 s 才生效；10 s 从第一次按下起算 |
| 复位按钮接线 | 一个按钮两组触点：一组到安全继电器复位端，一组到 PLC 输入；安全回路有问题时 PLC 收到复位也不采纳，以继电器触点反馈为准 |
| 急停按钮 | 三组触点：两组进安全继电器双通道，一组进 PLC；安全继电器的 41-42 常闭辅助触点进 PLC，1＝回路故障 |
| 恢复 | 复位后须再按启动才恢复；急停后默认重新初始化再启动（康宁）；客户要求断点续跑的（3Sun 的 DJ-2026-009）写进项目需求 |
| 双手启动 | 同步窗 0.5 s（常量），写成可改的常量 |
| 门锁 | 三组触点：两组串进安全继电器双通道（与急停同一继电器），一组进 PLC；PLC 输出直接驱动解锁，条件＝不在自动；门未关不许开机；无维修钥匙，不做门开点动；不设应急拉手（安环培训） |
| 开门流程 | 离开自动 → 按申请开门（灯 1 s 闪）→ 伺服停、动作全停 → 解锁（灯常亮）→ 关门复位后锁住，灯灭 |
| 急停时的输出 | 电机、伺服、变频器清零；**电磁阀不能一刀切复位**，按阀型逐点定（中封阀、真空发生器不许直接复位），IO 表加“急停/断线时输出”列；用户强调过两次，别再问 |
| 远程 IO 断线 | 按负载分：变频器清零，真空、气缸阀保持，伺服停机；断线为最高级报警 |
| 光栅 | 按规范草稿；急停恢复规则同上 |
| 通讯 | 通讯数据不当安全信号 |
| 机器人防撞区域许可 | 走专用硬接线 IO |
| 复位按钮卡住 | 不做卡住判定 |
| 现场临时跳线 | 只临时，回传时写拆除记录 |

## 四、现场回传

现场改了 PLC 程序，要回传，不然仓库里的程序和机器里的对不上：

1. **当天**上载程序、导出、记校验码（可以离线做）。
2. 放进项目 `11_监控/01_变更管理/04_现场回传/<日期>_<设备>/`（或该项目现行的监控目录布局），每件事一条业务变更（BC），说明前缀 `[现场]`。
3. 两个工作日内、**下次下载之前**，AI 做差异复核单，开“现场回传卡”PR。
4. 新增 `02_变更记录/03_下装记录.md`：**下载前 PLC 校验码必须等于最后一行**；不等，先回传。
5. 建议每个项目加程序版本常量 `GC_SW_VERSION`。

## 五、电气资料的分工

- 电路图（EPLAN）由用户改，不进安全签字门禁，**AI 不改图**；安全回路单独成页。
- 电气自动化安全规范要放进规范库 `00_Obsidian_Base`，需要用户单独同意；定稿前不要当作已入库规范引用。

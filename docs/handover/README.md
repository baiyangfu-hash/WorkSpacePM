## 用户是谁、怎么沟通

- 用户是电气工程师（PLC、HMI、三菱机器人、电路设计），懂一点 Python 和 C#，不是软件专业，**按结果验收、不看代码**。
- 讲话用现场话和产线类比；给 GitHub 网页操作要写逐步路径（哪个页面、点哪个按钮、做完看到什么）。

- 时间一律写 MST（UTC-7，无夏令时）。机器时钟是 UTC，先减 7 小时再写，并标 MST。不写 UTC。

# 变更单（CHG，相当于 ECN）- DJ-2026-009

这里只放**大事**的变更单。日常改程序、改文档不开 CHG，实施卡直接引用业务变更记录（BC）就够了。

## 什么时候开

| 情况 | 开不开 | 子目录 |
|---|---|---|
| 客户改需求、工艺参数变化、日常改程序或文档 | 不开 | — |
| PLC 程序作为正式版本下发到设备，或交付客户（发版） | 开 | `CHG-PLC/` |
| 安全相关（安全回路状态读取、急停逻辑等） | 开，单子上勾 SAFE | 按主要领域放 |
| 电气图纸、BOM 正式改版 | 开 | `CHG-ELEC/` |
| 交付文档正式改版 | 开 | `CHG-DOCU/` |

## 规矩

- 编号 `CHG-<领域>-<年>-<三位流水号>`，例如 `CHG-PLC-2026-002`；格式按 `00_Obsidian_Base全局规范文件仓库` 里的通用变更单模板（V2.1.0），不改。
- 一张 CHG 可以挂多张实施卡，一张卡最多挂一张 CHG。CHG 里**不抄卡号**，由脚本反查。
- 挂在这张 CHG 下的卡全部验收后，CHG 才能关闭；关闭后在 `../02_变更记录/01_版本变更台账.md` 记一行。
- 现有的 `CHG-PLC/CHG-PLC-2026-001.md` 修的是 PLC 技能索引漏引 LSP-904，属于工具缺陷，是旧制度下的单子，原样保留，不算业务变更。

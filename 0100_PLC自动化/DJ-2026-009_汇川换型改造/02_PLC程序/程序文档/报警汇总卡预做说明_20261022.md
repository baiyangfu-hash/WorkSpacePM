## 4. 报警码表（HMI 报警文本照这个做）

| 码 | 含义 | 来源 |
|:--:|------|------|
| 1～8 | 第 1～8 个急停被按下 | FB_1030 q_dwAlarm bit0～7 |
| 9～16 | 第 1～8 扇门没关好/没锁 | bit8～15 |
| 17～24 | 第 1～8 道光栅被遮挡（009 无光栅，预留） | bit16～23 |
| 25～28 | 第 1～4 个安全继电器反馈故障 | bit24～27 |
| 29 | 总线断线（远程 IO / SV660N） | bit28 |
| 30 / 31 / 32 | 复位被拒 / 复位过早（不足 10 s）/ 门锁回失败 | bit29 / 30 / 31 |
| 41 / 42 | 进料 / 出料握手因通讯故障中止 | FB_3001 q_wErrorCode bit0 / 1 |
| 43 | 自动作业中被中止，等人工复位 | bit2 |
| 45 / 46 | 上游 / 下游通讯故障 | bit4 / 5 |
| 47 / 48 | 上游 ID 不合格 / ID 待人工核对 | bit6 / 7 |

码越小越优先。复位（HMI `stGlobal.i_bReset`）只清历史、累计次数、新报警标志；还在的报警照常显示，不再记一次。`o_bNewAlarmFlag` 出现新报警置 1、按复位清，可以接蜂鸣器。

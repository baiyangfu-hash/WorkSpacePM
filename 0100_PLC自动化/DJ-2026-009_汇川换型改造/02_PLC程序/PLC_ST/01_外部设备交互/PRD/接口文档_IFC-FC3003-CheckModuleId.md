# 接口文档 (IFC) - FC_3003_CheckModuleId 组件 ID 合格检查

## 1. 接口功能定义

实施卡 `CARD-DJ-2026-009-003`（草稿）规则 R5，用户 2026-10-20 答复：现在只判断组件 ID 是不是空；校验单独做成一个可扩展的检查，以后加长度、格式校验或和 MES 核对，只改这一个函数，每种不合格原因占返回值的一个位。

ID 样例：`L06A20261020165232`（线别 `L06` + 班次 `A` + 时间戳到秒，18 个字符）。

## 2. 输入输出引脚表

| 变量名 | 类型 | 方向 | 说明 |
|:---|:---:|:---:|:---|
| `i_sModuleId` | STRING[32] | VAR_INPUT | 待检查的组件 ID |

返回值：WORD，16#0000 = 合格，其他 = 不合格原因位。

## 3. 常量（VAR CONSTANT，单独列出）

| 常量名 | 值 | 含义 |
|:---|:---:|:---|
| `ID_OK` | 16#0000 | 合格 |
| `ID_ERR_EMPTY` | 16#0001 | ID 为空 |

## 1. 技术选型与运行环境

- **PLC 控制器**: 西门子 S7-1200 / S7-1500 / 汇川 H5U / 欧姆龙 NJ/NX
- **编程语言**: IEC 61131-3 SCL / ST (结构化文本)
- **运动控制**: PLCopen Part 1 Motion Control 轴控制协议
- **人机界面 (HMI)**: 工业触摸屏 (GP-Pro EX / Pro-face / WinCC / 现代化 Web 原型)

## 2. 软件设计原则

1. **零全局耦合**: 业务 FB 内部禁止直接操作未经参数传入的全局变量，所有交互经 `io_st<Module>` 注入；
2. **零运行时死锁**: 所有 `CASE` 状态机必须包含 `ELSE` 分支与超时强制复位保护；
3. **单点出口原则**: 复杂功能块末尾执行统一的子 FB 调用与输出回写，避免分支中途 RETURN 导致状态遗留。

| # | 旧版 | 原程序实际 |
|---|---|---|
| 1 | 轴顺序 Z=X0/Y0、X1=X1/Y1、X2=X2/Y2 | **X1=X0/Y0/Y4，X2=X1/Y1/Y5，Z=X2/Y2/Y6**（轴 1 = X1，轴 2 = X2，轴 3 = Z） |
| 2 | X3~X10 为 Z / X1 / X2 的限位（顺序错） | X3/X4 = X1 前 / 后极限，X5/X6 = X2，X7/X10 = Z 上 / 下极限 |
| 3 | X11~X13 = Z / X1 / X2 伺服报警 | X11 = X1，X12 = X2，X13 = Z |
| 4 | X14/X15 = 后 / 前安全门锁，X16 = 急停，X17 = 复位 | X14~X17 = 变频器 1~4 异常；**急停 X101，复位 X100**，安全门 X140~X147 共 8 扇 |
| 5 | Y10~Y12 伺服使能，Y13 安全继电器启动 | 原程序**没有**伺服使能和安全继电器输出；Y10~Y23 是 4 层输送变频器正转 / 反转 / 慢速 |
| 6 | 4 层 / 3 层 / 2 层 / 1 层各自挂在“DO 扩展模块”Y0~Y15，含变频器复位 | 4 层执行器在 CPU 本体 Y10~Y37；**无变频器复位输出** |
| 7 | 分布式 IO NZ2MFB1-32DT ×2（取料气缸传感器、送料检测） | 原程序**没有**分布式 IO；夹爪 / 升降 / 小车光电全是本机输入 X60~X75、X124~X127 |
| 8 | 4 层 / 3 层 / 2 层 / 1 层感应器在 DI 扩展模块 3、4 | 在 X20~X57 与 X104~X123（每层 8 点 + 冗余上下位 4 点）、满料检测 X150~X157 |
| 9 | 没有 X76、X102 以外的打胶机 / 组框机硬接线 | 另有 Y44（抓料可）、Y45 / Y46（给组框机，被屏蔽）、Y47（安全区）、X160 / X161（组框机暂停 / 急停，未使用）、CC-Link R5000 / R5010 / R5011 |

## 6. 需要现场核对

1. **EPLAN 图纸页码**：旧版“原理图页码”列无法与原程序核对，本版不保留；需要电气图核对后补回。
2. **X160 / X161**（组框机开门暂停 / 急停）：落在第 5 块输入模块范围内但原程序不使用；现场是否已接线、新程序是否启用，见 Q7 后续。
3. **Y45 / Y46**（组框机暂停 / 急停）：原程序被 `/SM400` 屏蔽，恒 OFF；现场是否已接线待核对。
4. **X20 / X30 / X40 / X50**（各层放料检测光电）、**X103**（电控门检测 2）：原程序未使用；现场是否已装待核对。
5. **X75** 注释与 X74 重复（“后检测 1”），按用法判断应为后位第 2 个光电。
6. **变频器慢速**：Y12 / Y15 / Y20 / Y23 单独 ON 不使电机转动，须与正转或反转同时有效（FB_1012 的“慢速修饰”语义与此一致）。

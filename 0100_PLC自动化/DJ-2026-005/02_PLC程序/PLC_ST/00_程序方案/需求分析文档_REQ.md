## 3. 项目背景

### 3.1 项目来源
边框缓存机配合打胶机使用：把铝型材方管边框（约 30×20 mm，长边 / 短边）按层缓存，两根一对取出，放到送料小车，满一套（4 根）后在打胶机允许时送到打胶机取料点。现有 FX5U 程序已在现场运行，本项目把控制逻辑**按原工艺**改写为 ST（`PLC_ST` 路线），沿用原 IO、电气和机构。

### 3.2 业务目标
1. 工艺行为与原程序一致（成对取料、先前位后后位、4 层输送、X2 小车与打胶机握手），原程序中已确认的缺陷按本文第 6 节修正。
2. 一个机构一个功能块，步序和状态可读，IO / 点位 / 时间集中配置，便于将来机构改造（009 单次取料）。
3. 保证安全行为不低于原程序：急停、8 扇安全门、伺服和变频器报警。

### 3.3 范围
**在范围内**：模式管理（手动 / 回原点 / 准备 / 自动 / 暂停 / 停止 / 异常 / 急停）、示教与手动、4 层输送机、取放料机构（X1 / Z / 前后夹爪 / 升降缸）、X2 送料小车、与打胶机和组框机的握手、报警、声光指示、HMI 接口软元件。
**不在范围内**：HMI 画面设计（HMI 是 GP-Pro EX 工程，另立）、电气接线、伺服与变频器参数、单次取料（属 009 机构改造）、MES 上传（原程序没有）。

| R-NFR-03 | 安全 | 急停 X101、门 X140~X147、伺服 / 变频器报警按常闭输入读取，断线按动作处理；急停类动作不得因任何“旁路”失效（禁止 `OR TRUE` 之类旁路）；软件不替代硬件安全回路 |
| R-NFR-04 | 扫描周期 | 小于 100 ms；各 FB 不含阻塞循环 |
| R-NFR-05 | 规范 | LSP-905 命名与语法白名单、OB1 ≤ 10 行、VAR_IN_OUT 整块传递、CASE 必有 ELSE、plc check 无新增失败 |
| R-NFR-06 | 可维护 | 一个机构一个 FB；步序用具名常量；IO、点位、时间集中配置 |
| R-NFR-07 | 本机模拟（M500） | 保留台架调试用的“本机模拟”开关：置位时准备的传感器条件和夹料检测报警被屏蔽；默认关，不得在自动生产中置位 |

## 6. 对原程序的修正清单（已由用户 2026-10-23 认可处理方向）

对应 [PRC 第 8 节](020_原程序工艺说明_PRC.md) 的 18 项，逐项在本文第 4 节标“修正”。其中以下几项**不是**“修错”而是语义决策，评审时请重点看：
1. R-MODE-03 / 04：暂停与停止的新语义。
2. R-HOME-02 + R-MAN-07：夹爪有料时回原点的处理方式，同时新增手动松夹爪。
3. R-CONV-05：本层报警只停本层；R-FEED-07：报警时小车立即停。
4. R-EXT-02：M501 = M502 = 0 的解释。
5. R-EXT-04：启用 Y45 / Y46（现场是否接线未核对）。
6. R-FEED-05：X102 为必需，10 s 无 X102 只报提示。

## 7. 约束条件

- 编程语言：IEC 61131-3 SCL（PLC_ST 路线，LSP-905 语法白名单）。
- 共享库：SysLib（FB_TON / FB_TONR、FB_1011 气缸、FB_1012 电机、ST_ServoAxis）。定时器块当前按扫描次数计时，毫秒修正见 PR #89（上机前须合并）。
- 枚举：目标平台 TIA V19 无枚举，状态用 INT 值 + 具名常量；规范 LSP-905 V1.3.0 已加 ENUM 供其他平台（见 TEC 4.1）。
- 数据块：GlobalVars 为唯一全局数据块，各 FB 通过结构体 VAR_IN_OUT 交换数据。
- HMI：沿用原 HMI 工程的软元件语义（见 INT 第 7 节），新程序提供同名功能位；HMI 变量映射表另行核对。

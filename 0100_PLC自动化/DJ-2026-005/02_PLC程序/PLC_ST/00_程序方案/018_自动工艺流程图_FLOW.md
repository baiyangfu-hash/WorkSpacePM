## 3. 整机工艺总览

```mermaid
flowchart LR
    C["4 层输送机<br/>每层把边框送到取料位<br/>发『请求取料』"] --> P["取放料机构<br/>X1 到取料点 → Z 升 → 两爪夹<br/>→ X1 横移 → Z 降 → 松开"]
    P --> F["X2 送料小车<br/>前位 / 后位放满<br/>→ 去打胶机放料点"]
    F --> G["打胶机<br/>取走边框（X102）"]
    G --> Z["组框机（下游的下游）<br/>只经 CC-Link 通讯：安全 / 允许送料"]
    P -. 取料完成 本层对本层 .-> C
    F -. A / B 请求 .-> P
    P -. X1 前/后送料完成 .-> F
```

要点：4 层叠放（每层 2500 × 2500 × 200 mm）；夹爪 1~4 从左到右；前位抓 3、4 层，后位抓 1、2 层；成对取料（单次取料不在 005 做）。

## 4. 模式状态图（FB_1001）

```mermaid
stateDiagram-v2

    待机 --> 准备: 自动运行键↑ ∧ 已回原点 ∧ 无报警
    准备 --> 自动: 准备完成（自动进入，不再按键）
    自动 --> 待机: 【新】停止请求 ∧ 本循环结束
    待机 --> 手动: HMI 手动
    准备 --> 手动
    自动 --> 手动
    回原点 --> 手动
    手动 --> 待机: HMI 复位
    自动 --> 异常: 急停 / 门 / 伺服 / 变频器
    准备 --> 异常
```

## 5. 回原点与准备（FB_1005）

```mermaid
flowchart TD
    A[回原点启动] --> B{夹爪有料<br/>X60~X63 任一?}
    B -- 是 --> B1[F80 报警 不松夹爪<br/>等人工处理]:::alarm
    B -- 否 --> C[松开夹爪<br/>升降缸下降<br/>输送机同时初始化]
    C --> D{升降缸下位 ∧<br/>4 松开位全到?}
    D -- 否 --> C
    D -- 是 --> E[Z 回原点]
    E --> F{小车有料<br/>X72~X75 任一?}
    F -- 是 --> F1[F81 报警 禁止 X2 回原点]:::alarm
    F -- 否 --> G[X1、X2 同时回原点]
    E --> G
    G --> H[已回原点 = 1]
    H --> I[准备]
    I --> J[松开夹爪 / 升降缸下降]
    J --> K[Z 到待机点 D500]
    K --> L[X1 到 D510<br/>【新】到位才算初始化完成]
    L --> M[X2 到 D512]

    N -- 否 --> N

    classDef alarm fill:#fdd,stroke:#c00
```

任何非提示类报警：回原点撤销，排除后“从头再回”当前步。

## 6. 4 层输送机单层状态机（FB_1002，10 步）

```mermaid
stateDiagram-v2
    [*] --> S0
    S0: 步0 分支
    S1: 步1 状态判断
    S2: 步2 初始化反转 10 s
    S10: 步10 阻挡升起 输送运行
    S20: 步20 到阻挡前，延 3 s 停
    S30: 步30 分料气缸下降
    S50: 步50 阻挡气缸下降
    S60: 步60 慢速送到取料位 延 2 s
    S70: 步70 到位，请求取料
    S80: 步80 等取料完成
    S0 --> S1: 初始化请求 ∧ 未准备完成<br/>或 退料
    S1 --> S2: 阻挡下位 ∧ 分料上位 ∧ 安全区
    S2 --> S0: 10 s 到 → 准备完成=1
    S0 --> S10: 自动 ∧ 准备完成 ∧ 安全区 ∧ 取料位开关均灭
    S0 --> S60: 自动 ∧ 准备完成 ∧ 安全区 ∧ 取料位开关任一亮
    S10 --> S20: 阻挡上位 ∧ 分料上位 ∧ 安全区 → 正转
    S20 --> S30: 阻挡前到位 3 s
    S30 --> S50: 分料下位 1、2 亮
    S50 --> S60: 阻挡下位 1、2 亮
    S60 --> S70: 取料位开关 1、2 亮后 2 s
    S70 --> S80: 阻挡上位 ∧ 电机停 → 请求取料=1
    S80 --> S10: 取料位开关均灭后<br/>本层取料完成→1 s 否则 8 s
```

并行：满料 1 ∧ 2 ∧ 正转 → 慢速；缺料（正转连续 10 s 且阻挡前、取料位均无料）→ 本层 F100~F103；气缸位置 5 s 报警；暂停时电机切断、步序保持、定时器清零；异常 / 退料 → 步 0、阻挡 / 分料升起。

## 7. 取放料 S20~S25（FB_1003）

```mermaid
stateDiagram-v2
    [*] --> S20
    S20: S20 待料<br/>Z 先到待机点 D500<br/>再 X1 到取料点
    S21: S21 取料准备<br/>升降缸上升 → Z 升到取料高度
    S22: S22 夹紧<br/>前后夹爪同夹<br/>夹紧位 + 产品检测全亮
    S23: S23 横移<br/>X1 到放料点
    S24: S24 放料<br/>置『取料完成』<br/>升降缸下降 → Z 降到放料高度
    S25: S25 松开<br/>置『X1 送料完成』
    S20 --> S21: Z、X1 到位 ∧ A/B 请求满 0.5 s ∧ 对应两层有请求
    S21 --> S22: 4 松开位 ∧ 升降缸上位【新】 → Z 到位
    S22 --> S23: 夹紧到位 ∧ X60~X63 全亮
    S22 --> S22: 5 s 未夹到【新】F106 报警并等待
    S23 --> S24: X1 到位
    S24 --> S25: 升降缸下位 ∧ Z 到位
    S25 --> S20: 松开位全到 ∧ 0.5 s
```

对号：A（前位）= 3、4 层；B（后位）= 1、2 层，`iPair` 在 S20 选定并锁存到 S25。暂停 / Hold：轴 `Halt`，恢复后在当前步重新定位；夹爪与升降缸保持。M8：步序回 0，**夹爪不松**。

## 8. X2 送料小车（FB_1004，D760 四步）

```mermaid
stateDiagram-v2
    [*] --> T0
    T0: 步0 回取料点 D512
    T1: 步1 在 D512 生成 A/B 请求
    T2: 步2 去打胶机放料点 D522
    T3: 步3 Y44 抓料可，等打胶机取走
    T0 --> T1: 取放料在 S20 ∧ Z 在待机点 ∧ 三轴不动 → X2 到位
    T1 --> T2: (前后位都放过 ∨ 光电全亮 10 s) ∧ 光电全亮 ∧ Z 在待机点
    T2 --> T3: 光电全亮 ∧ X76 ∧ 送框允许 → 到 D522
    T3 --> T0: 光电全灭 ∧ X102↑
    T3 --> T0: 全灭持续 10 s（无 X102）→ 回步 0（原程序二选一）
```

送框允许 = ¬M501 ∨ M502 ∨ M510（单套）。X76 只在出发时判一次。Y47 = X2 在 D512 ∧ 不在驱动 ∧ 自动。

## 9. 暂停 / 停止 / 报警 / 急停

```mermaid
flowchart TD
    E{事件}
    E -- 暂停 M95 --> P1[各机构 Hold：步序冻结<br/>电机切断 / 轴 Halt<br/>夹爪、气缸保持] --> P2[M95 复位 → 原地继续]
    E -- 停止 M7 / X77 --> S1[F12 提示<br/>各机构跑完本循环到起点] --> S2[退出自动<br/>已回原点保留]
    E -- 本机构 B 类报警 --> B1[仅该机构 Hold<br/>其余机构继续] --> B2[原因消失 + 复位键<br/>→ 继续]
    E -- 急停 / 门 / 伺服 / 变频器 --> M1[M8：清步序 / 清已回原点<br/>轴 Stop 电机停<br/>夹爪升降缸保持] --> M2[排除原因 → 复位键一次<br/>→ 重新回原点]
```

## 10. 小结（与旧版图的关键更正）

| 项 | 旧图（Trae） | 本版 |
|---|---|---|
| 输送机 | 9 步 | 10 步（0/1/2/10/20/30/50/60/70/80） |
| 小车 | D610/D620/D630 | D760 四步（0~3），点位 D512 / D522 |
| 取放料 | 4 组夹爪 | 前后各 2 爪，成对取（前位 3+4，后位 1+2） |
| 停止 | 冻结 | 本循环结束后退出自动【新】 |
| M8 恢复 | 按两次 | 按一次【新】 |

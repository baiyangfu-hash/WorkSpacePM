## 4. 模式与调度

### 4.1 FB_1001 机器模式（R-MODE-01~08）

**模式变量**：`o_bManual / o_bHoming / o_bPrepare / o_bAuto`（互斥）、`o_bHomeDone`（M94）、`o_bFault`（M8）、`o_bPause`、`o_bStopPending`、`o_iDeviceState`（D116）。

**进入条件**（上升沿 / 电平沿用 PRC 2）：

| 模式 | 进入 | 退出 |
|---|---|---|
| 手动 | HMI `i_bManual` 置位且无 M8、无 F12 未复位 | HMI 复位；M8 时强制退出 |
| 回原点 | 复位键上升沿 ∧ ¬M8 ∧ ¬已回原点 ∧ ¬手动 ∧ ¬自动 ∧ ¬任一报警 | 三轴原点完成；M8；进手动 |
| 准备 | HMI 自动运行键上升沿 ∧ 已回原点 ∧ ¬准备 ∧ ¬自动 ∧ ¬手动 ∧ ¬任一报警 | 准备完成；M8；进手动 |
| 自动 | 准备完成（上升沿）或（自动运行键上升沿 ∧ 准备完成标志已有）∧ ¬自动 ∧ ¬手动 | M8；进手动；停止请求完成 |

- “任一报警”指非提示类的任一已锁存报警。
- 进手动时：强制复位自动、准备、回原点（取消 Homing 序列，轴 Stop），**不清已回原点标志**。
- M8 时：同时清已回原点标志、清所有序列、轴 Stop；复位键一次即清报警（R-MODE-06：同一次按键既清锁存又允许下一扫描启动回原点，因启动条件检查“无报警”改为检查“无未清除的 M8 类锁存”）。

**暂停**：HMI `i_bPause`（M95）置位 → `o_bPause`；所有机构视为 Hold，解除后继续。D116 = 10（优先级仅次于异常）。
**停止**：`i_bStop`（M7）或触摸屏 STOP（X77 常闭，断开 = 动作）→ 置 `o_bStopPending`；各机构回到“循环起点”（输送在待机步 0 / 10、取放料 S20、小车步 0 / 1）后，FB_1001 复位 `o_bAuto`、清 `o_bStopPending`，保留已回原点。此期间 F12 置位为提示类报警，用户松开 STOP 并按复位后清除。
**停止期间禁止开新循环**（`bStopPending` 为真时，各机构只收尾、不起新活，到达“静止点”后保持，直到 FB_1001 退出自动）：
- 输送（FB_1002）：步 0 不再转 10 / 60；步 80 回到步 10 的转移改为回步 0 并保持；已经在步 10~70 的这一块料走完到步 80 为止。静止点 = 步 0（或步 70 / 80 等待取料完成的稳态不算静止，取走后进步 0）。
- 取放料（FB_1003）：S20 不再因 A / B 请求出发；已在 S21~S25 的走完回 S20，静止点 = S20。
- 小车（FB_1004）：步 0 不再出发，步 1 不再生成 A / B 请求，步 2 不再出发（已在 D522 上等待取走的步 3 走完回步 0，静止点 = 步 0 / 1）。
- 退出条件：三类静止点同时成立 → FB_1001 复位 `o_bAuto`、清 `o_bStopPending`；保持期间报警 / 暂停照常生效。
**D116**：异常 8 > 暂停 10 > 自动 5 > 准备 3 > 回原点 2 > 手动 1 > 待机 6。

**机器级报警触发（本 FB 产生，写入 `stAlarm.arrTrig`）**：

| F | 触发条件（level） | 延时 | 类 |
|---|---|---|---|
| F0 | ¬X101（急停常闭断开） | 0 | A |
| F1~F8 | ¬X140~X147 | 0 | A |
| F9 / F10 / F11 | ¬X11 / ¬X12 / ¬X13（X1 / X2 / Z 伺服报警） | 0 | A |
| F12 | `i_bStop` ∨ ¬X77 | 0 | 提示（驱动 `o_bStopPending`） |
| F13~F16 | ¬X14~X17（变频器 1~4） | 0 | A |
| F20 / F21 | ¬X3 / ¬X4 ∧ 自动 | 0 | B（取放料） |
| F22 / F23 | ¬X5 / ¬X6 ∧ 自动 | 0 | B（小车） |
| F24 / F25 | ¬X7 / ¬X10 ∧ 自动 | 0 | B（取放料） |

### 4.2 FB_1005 回原点与准备（R-HOME-*、R-PREP-*）

**回原点序列** `s_iStep`：

| 步 | 动作 | 转移 |
|---|---|---|
| 0 待机 | — | 回原点模式启动 → 10 |
| 10 预处理 | 若夹爪有料（X60~X63 任一）：F80 触发，**不松夹爪**，等待人工；否则：前夹爪松开位到（X67 ∧ X127）且升降缸不在下位 → 升降缸下降；任一松开位未到 → 松开夹爪（RST 夹紧输出）。输送机同时启动初始化（`bInitRequest`） | 升降缸下位 ∧ 4 松开位全到 → 20 |
| 20 Z 回原点 | 条件：升降缸下位 X71、4 松开位亮；Z `Home.Execute` | Z `Home.Done` → 30 |
| 30 X1 / X2 回原点 | X1 `Home.Execute`；X2 `Home.Execute`（要求 ¬F81：小车无料） | 两者 Done → 40 |
| 40 完成 | `o_bHomeDone := TRUE`；清回原点模式 | → 0 |

- 任何非提示类报警：`Home.Execute` 撤销（轴减速停），报警清除后在当前步重新发 `Execute`，即“从头再回”该步（R-HOME-04）。
- F80 / F81 触发：F80 = 回原点模式 ∧ X60~X63 任一亮；F81 = 回原点模式 ∧ X72~X75 任一亮。F80 同时禁止 Z 的所有定位命令（沿用）。回原点速度取参数 `rHomeSpeed`（默认 1000，待现场确认，R-HOME-06）。

**准备序列**：

| 步 | 动作 | 转移 |
|---|---|---|
| 0 待机 | — | 准备模式启动 → 10 |
| 10 夹爪 / 升降缸 | 松开夹爪、升降缸下降（无条件，沿用） | → 20 |
| 20 Z 回待机点 | 条件（4 松开位 ∧ X71 下位，或本机模拟）持续 `dPrepZDelayMs`（300）后，Z 绝对定位到 D500（参数，初值 100） | Z Done → 30 |
| 30 X1 到 D510 | Z 完成后延时 `dPrepX1DelayMs`（500），X1 绝对定位 D510 | **X1 到位** → 40（R-PREP-02） |
| 40 X2 到 D512 | X1、Z 都完成后延时 `dPrepX2DelayMs`（1000），X2 绝对定位 D512 | Done → 50 |
| 50 等输送 | 轴初始化完成置位；等 4 层“准备完成” | 全到 → 60 |
| 60 完成 | 输出 `o_bPrepareDone` 一拍；FB_1001 自动进入自动 | → 0 |

- 速度：全部取 D600 自动速度（R-PREP-03）；D500 不再强制覆盖，由 HMI 设置，若为 0 则用默认 100。

### 5.1 FB_1002 单层状态机

输入见 INT 第 4.2。`ST` 结构体字段沿用旧 `ST_SingleLayerConveyor` 的命名风格，重新整理（INT 为准）。

| 步 | 动作 | 转移条件 | 定时 |
|---|---|---|---|
| 0 | 请求取料 := 0；`bInitReq ∧ ¬准备完成` → 1；`自动运行 ∧ 准备完成 ∧ 安全区`：取料位开关 1、2 都灭 → 10，任一亮 → 60；`¬自动 ∧ ¬初始化请求 ∧ 退料` → 1 | 见左 | — |
| 1 | 阻挡下降（命令 TRUE）、分料升起 | 安全区 ∧ 阻挡上位 1、2 灭 ∧ 分料上位 1、2 亮 ∧ 阻挡下位 1、2 亮 ∧ 分料下位 1、2 灭 → 2 | — |
| 2 | 首次进入：反转 := 1，启动 10 s 计时；到时：反转 := 0，慢速 := 0，准备完成 := 1，退料 := 0 | 到时 → 0 | `dInitRevMs`=10000 |
| 10 | 请求取料 := 0；阻挡上位 1、2 都灭时：（自动运行时）阻挡升起；否则分料升起。安全区 ∧ 阻挡上位 1、2 亮 ∧ 分料上位 1、2 亮 → 正转 := 1，慢速 := 0 | 同左 → 20 | — |
| 20 | 阻挡前到位传感器亮：启动 3 s 计时（置标志后即使传感器掉了也继续）；3 s 到：正转 := 0 | 到时 → 30 | `dPreBlockMs`=3000 |
| 30 | 清到位延时标志；阻挡前到位 ∧ 分料上位 1、2 亮：分料下降；分料下位 1、2 亮 | 分料下位 1、2 亮 → 50 | — |
| 50 | 仅当“取料位开关 1、2 都灭 ∧ 阻挡前到位亮”：阻挡下位 1、2 都灭 → 阻挡下降；阻挡下位 1、2 都亮 → 步 60 | 同左 | — |
| 60 | 安全区内：正转 := 1；取料位开关 1、2 都亮 → 慢速 := 1 并启动 2 s 计时，否则慢速 := 0（计时标志一旦置位不撤）。不在安全区：正转、慢速 := 0 并清计时标志 | 计时到 → 正转 := 0，慢速 := 0 → 70 | `dSlowFeedMs`=2000 |
| 70 | 清计时标志；阻挡升起 | 取料位开关 1、2 亮 ∧ 阻挡上位 1、2 亮 ∧ 慢速 / 正转均 0 → 请求取料 := 1 → 80 | — |
| 80 | 取料位开关 1、2 都灭时：本层“取料完成” ∧ → 设定 1000 ms，否则 8000 ms，启动计时（**每扫描重新判断设定值**）；请求取料保持 1 | 计时到 → 10 | `dReleaseMs`=1000/8000 |
| ELSE | 回步 0 | — | — |

**并行逻辑**：
- 满料减速：满料 1 ∧ 满料 2 ∧ 正转输出 → 慢速立即有效；条件消失立即撤销（原程序的 5 s 定时器输出未被使用，不实现）。
- 暂停 / 本层 Hold：正转、反转输出 := FALSE；慢速命令随方向（FB_1012 约定，无方向时慢速自动无效）；阻挡 / 分料气缸命令保持；所有 FB_TON 的 `IN` := FALSE。
- 异常停机（M8 ∨ 进手动）或退料上升沿：`s_iStep := 0`，计时标志清零，阻挡升起、分料升起，电机命令清零，准备完成 := 0，请求取料 := 0；`ELSE` 保持。异常停机为真期间 CASE 不执行。
- 气缸执行用 `FB_1011`：阻挡 / 分料各一个，`SolenoidType := 0`（单线圈），命令 `Extend` = 阻挡下降 / 分料下降（Y30 / Y31 ON），传感器 = 上 / 下位的“1 与 2”**分别**参与报警，**合并（1 ∧ 2）**参与到位判断。
- 缺料（R-CONV-05）：实际正转输出连续 10 s 且 ¬阻挡前到位 ∧ ¬（取料位开关 1 ∧ 2）→ 触发本层缺料（F100~F103，**层号 = 4 − 编号 + … 即 F100 = 4 层、F103 = 1 层**）。
- 安全区输入来自 Bridge；步 1、10、60 使用。

F 号映射：1 层 F34~F41（阻挡上 1 = F34，阻挡上 2 = F35，阻挡下 1 = F36，阻挡下 2 = F37，分料上 1 = F38，分料上 2 = F39，分料下 1 = F40，分料下 2 = F41），2 层 +8，3 层 +16，4 层 +24。**F47 的“T_0[17] / T17 混用”缺陷不复现**（新代码每个 F 一个定时器）。

## 6. 取放料机构（R-PP-*）

**FB_1003** 步 `s_iStep`：0 未激活，20~25 对应 S20~S25。自动且三轴（X1 / X2 / Z）都不在驱动且无 Hold → 进入 20。每步内部子相：`0` 入口窗口（0.5 s），`1` 轴运动，`2` 已完成等转移。

**对号选择**：`s_iPair`（1 = 前位对 3+4 层，2 = 后位对 1+2 层）在 S20 由 A / B 请求选定并锁存到 S25。点位取自 `astPair[s_iPair]`：`rXPick / rZPick / rXPlace`；`rZPlace` 前后位共用。

| 步 | 入口窗口（0.5 s）动作 | 条件与动作 | 转移 |
|---|---|---|---|
| S20 | 松开两爪（`ZRST Y40~Y41`）；清 4 个“取料完成”；Z 目标 := D500；速度 := D600 | Z 先动：`¬三轴驱动 ∧ ¬Z 到位` → Z 绝对定位 D500。X1 后动：Z 到位 ∧ (A ∧ 层 3、4 请求 ∨ B ∧ 层 1、2 请求) ∧ A 或 B 出现满 0.5 s → X1 绝对定位 `rXPick`（A：D510；B：D540） | Z、X1 都到位 → S21 |
| S21 | 升降缸上升；速度 := D600 | 4 个夹爪松开位亮 ∧ 4 个夹紧位灭 ∧ 层请求仍在 ∧ **升降缸上位 X70**（R-PP-10，新增）→ Z 绝对定位 `rZPick`（A：D514；B：D544） | Z 到位 → S22 |
| S22 | — （无窗口） | X70 亮 → 前后夹爪同时夹紧；夹紧位 4 亮 ∧ 松开位 4 灭 ∧ X60~X63 全亮 | → S23；`dClampTimeoutMs`（默认 5000）内不满足 → F106 夹紧超时报警（R-PP-05）并停在 S22 |
| S23 | 窗口：速度 := D600 | X1 绝对定位 `rXPlace`（A：D520；B：D550）；Z、夹爪、升降缸不动 | X1 到位 → S24 |
| S24 | 窗口：置“取料完成”（A：4、3；B：2、1），清对应“X1 送料完成”；Z 目标 := D524；速度 := D600 | 升降缸下降（一进步即命令）；窗口后：升降缸下位 X71 亮 ∧ 上位 X70 灭 → Z 绝对定位 D524 | Z 到位 → S25 |
| S25 | 松开两爪；`dSettleMs` 计时 | 计时到：A → 置“X1 前送料完成”；B → 置“X1 后送料完成”；松开位 4 亮 | → S20 |
| ELSE | 回 0 | — | — |

- Hold / 暂停：对运动中的轴 `Halt`；恢复后在当前步重新发 `Execute`；夹爪 / 升降缸命令保持。
- M8 / 进手动：`s_iStep := 0`，轴 Stop，**Y40~Y43 不动**。
- 报警（本机构类）：
  - F30 / F31：后夹爪夹紧命令 ON ∧ ¬前夹料产品检测 1 / 2（原程序命名交叉保持，见 REQ Q-C），5 s，且非本机模拟。
  - F32 / F33：前夹爪夹紧命令 ON ∧ ¬后夹料产品检测 1 / 2，5 s，且非本机模拟（M500，与 F30 / F31 同，R-NFR-07）。
  - F66~F73：夹紧 / 松开位与命令不符各 5 s（后夹紧 1、2，后松开 1、2，前夹紧 1、2，前松开 1、2）。
  - F74 / F75：升降缸上升 / 下降命令后 5 s 上位 / 下位未到。
- 自动速度 D600 的加减在本 FB（R-PP-11）：M700 / M701 上升沿 + 重复，夹在 [10000, 100000]。

## 7. X2 送料小车（R-FEED-*）

**FB_1004** 步 `s_iStep` = D760：

| 步 | 动作 | 转移 |
|---|---|---|
| 0 | 入口 0.5 s 装目标 D512 / 速度 D600。出发联锁：取放料在 S20 ∧ Z 到位 ∧ Z 当前位置 = D500 ∧ X1/X2/Z 不在驱动 ∧ ¬Hold → X2 绝对定位 D512（若已在 D512 则直接完成） | 到位 → 1 |
| 1 | 仅当 X2 在 D512：**前位请求 A** = 4 光电全灭 ∧ ¬X1 前送料完成；**后位请求 B** = X72 ∧ X73 ∧ ¬X74 ∧ ¬X75 ∧ ¬X1 后送料完成；4 光电全亮计 10 s | (X1 前、后送料完成都有 ∨ 10 s 到) ∧ Z 当前 = D500 ∧ 4 光电全亮 ∧ 三轴不动 → 2 |
| 2 | 入口 0.5 s：装目标 D522 / 速度；清两个“X1 送料完成”。出发：4 光电全亮 ∧ X76 ∧ 送框允许（INT 7.2）∧ X2 ≠ D522 → X2 绝对定位 D522（X76 只在出发时判一次，之后掉了也不停车）。若进入时 D512 = D522，直接走完（原程序卡死，R-FEED 新增处理） | 到位 → 3 |
| 3 | X2 在 D522 ∧ 4 光电全亮 → **Y44 = 1**，消耗一次单套送框许可；Y44 为 OUT（任一光电灭即 0） | 4 光电全灭 ∧ X102 上升沿 → 0；4 光电全灭 10 s 未收到 X102 → 触发提示类 F-小车（仍停在步 3 等待）（R-FEED-05） |
| ELSE | 回 0 | — |

- **Y47** = X2 在 D512 ∧ 不在驱动 ∧ 自动模式（与步号无关）。
- Hold / 暂停：X2 `Halt`，恢复后重发 `Execute`；M8：Stop，步序回 0，清 Y44 / Y47。
- 光电报警：F90 = (¬X72 ∨ ¬X73) ∧ X1 前送料完成，1 s；F91 = (¬X74 ∨ ¬X75) ∧ X1 后送料完成，1 s。
- 极限：F22 / F23（见 4.1）。

## 8. 外部设备（R-EXT-*）

**FB_3001 组框机链路**：
- 输出 R5000.0 = F0 ∨ F1~F8；Y45 = (M501 ∧ 组框机安全异常) ∨ R5000.0；Y46 同；X160 / X161 读入后并入“组框机安全异常”（待现场确认，R-EXT-04）。
- 通讯异常 = M501 ∧ (SB49 ∨ SB6A ∨ SB0A1) → F105（提示）；组框机安全异常 = M501 ∧ ¬通讯异常 ∧ R5010.0 → F104（A 类）。
- M510 单套送框：M501 ∧ R5011.0 上升沿置位；M501 ∧ R5011.0 下降沿复位；小车步 3 的 Y44 条件成立时复位。
- 小车出发“送框允许”：`¬M501 ∨ M502 ∨ M510`（R-EXT-02：M501 = 0 即不联机，只受 X76 约束）。
- M501 ∧ R5010.0：小车 X2 定位禁止；转移禁止（手动时除外）。

## 9. 报警与声光（FB_2001，R-ALM-*）

- 接口：`io_stAlarm` 持有 `arrTrig[0..127]`（各机构每扫描写入，一位一写）和 `arrLatch[0..127]`（输出）。
- 锁存：`trig` → `latch := TRUE`；复位键上升沿 ∧ ¬`trig` → `latch := FALSE`（原因消失后才可清）。
- 分类表（INT 第 9 节）：A（M8）、B 输送 n、B 取放料、B 小车、B 回原点、提示。输出：`o_bFault`（A 任一）、`o_bHoldConv[1..4]`、`o_bHoldPP`、`o_bHoldFeeder`、`o_bHoldHome`、`o_bAnyAlarm`（非提示任一）、`o_iAlarmNo`（最小 F 号，给 HMI D117）。
- 声光输出（沿用 PRC 7.2）：

| 灯 / 蜂鸣 | 条件 |
|---|---|
| 杆灯黄 Y26 | N ∧ ¬M8 |
| 蜂鸣 Y27 | N ∧ ¬M9 |
| 杆灯红 Y25 | N ∧ ¬回原点 ∧ ¬准备 |
| 复位灯 Y50 | `o_bAnyAlarm` ∧ 1 s 时钟 |
| 杆灯绿 Y24 | (手动 ∧ 1 s) ∨ (自动 ∧ ¬任一报警) ∨ ((回原点 ∨ 准备 ∨ (¬自动 ∧ ¬手动 ∧ M515)) ∧ 100 ms 时钟) |

其中 N = ((任一报警 ∨ 暂停 / Hold) ∧ 1 s 时钟) ∨ ((回原点 ∨ (手动 ∧ M515) ∨ 准备) ∧ 100 ms 时钟)。1 s / 100 ms 时钟由 `FB_TaktGenerator`（SysLib）产生。

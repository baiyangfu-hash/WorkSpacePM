## 4. 关键技术决策

### 4.1 状态与枚举
用户 10-24 倾向直接用 ENUM，但目标平台为 **TIA Portal V19**（用户 10-24 答复）：V19 的 SCL 没有枚举，命名值类型要 V20 及以上才有。因此 005 **回退为 `INT` + 具名常量**：
- 状态变量 `s_iStep`（INT），常量放 `VAR CONSTANT`，数值表写在接口文档 INT 第 8 节，作为跨 FB 的唯一约定。
- 规范 LSP-905 V1.3.0 已新增 ENUM 一节（#94，供 InoProShop 等支持枚举的平台，以及 V20+ 的博图），005 暂不用。将来 005 升到 V20 或换平台时，常量表可原样换成枚举，数值不变。

### 4.2 定时器
- 全部使用 SysLib `FB_TON` / `FB_TONR`，PT / ET 为 DINT 毫秒，三段式 + 集中批量调用（LSP-903 V2.1.0）。
- 原程序 `TIMER_100_FB_M`（非保持型、执行条件断开清零，用户 2026-10-23 确认）对应 `FB_TON`；暂停时 `IN` 置 FALSE → 清零，解除后重新计时。
- **注意（需用户知悉）**：用户选择“005 先用平台自带定时器”。LSP-905 §4.3 禁止 `TIME` 类型和 `T#` 字面量，工具链不接受平台 `TON(PT:=T#…)`，所以本方案落地为：代码只依赖 `FB_TON` / `FB_TONR` 的“PT 单位毫秒”接口约定，接口不变；库内部当前按扫描次数计时（缺陷），修正由 PR #89 负责，**上机前 #89 必须合并并换用修正后的库**。代码侧不再为此做任何兼容。
- 时间值（原程序 K × 100 ms）集中在各机构参数结构体，初值 = 原值。

### 4.3 轴与位置
- Z / X1 / X2 三个 `ST_ServoAxis`（`astServoAxis[1..3]`，**沿用现有 GlobalVars 顺序**：1 = Z、2 = X1、3 = X2，避免打乱平台侧轴对象编号）。注意这与原程序的“轴 1 = X1、轴 2 = X2、轴 3 = Z”编号不同，物理输出按 IO 表：X1 = Y0 / Y4，X2 = Y1 / Y5，Z = Y2 / Y6。
- 位置单位：脉冲（`REAL`），与原程序 D 寄存器值一致；换算由平台轴对象负责，本程序不做 mm 换算。
- 运动命令：绝对定位 = 设 `Abs.Position / Velocity`，`Abs.Execute` 保持直到 `Abs.Done`；暂停用 `Halt`，急停类用 `Stop`；回原点用 `Home`；点动用 `Jog`。
- 极限开关：硬件接线由轴对象处理，同时程序读取 X3~X10 做报警（F20~F25）。

### 4.4 安全
- 急停 X101、门 X140~X147 按常闭读取；信号丢失按动作处理；软件只做控制层响应，**不替代硬件安全回路**。是否另有硬件切断伺服 / 变频器电源待确认（REQ Q-G）。
- 不允许 `OR TRUE` 类旁路；安全相关逻辑改动走“安全签字”流程（AGENTS 安全区规则），本项目急停 / 门 / 联锁相关代码在 PR 中单独标注。
- `M500` 本机模拟保留为参数位，默认 FALSE，不得在自动生产中置位。

### 4.5 数据组织
- `GlobalVars.db` 为唯一全局数据块，每个机构一个结构体（`ST_*`），FB 通过 `VAR_IN_OUT` 整块读写。
- OB1 只做 FB 调用（≤ 10 行）；机构之间的信号中继放在专用 FB `FB_2002_StationBridge`，不写进 OB1（LSP-905 §4.5）。
- 配置（点位、时间、模式开关）放在机构结构体的参数段，HMI 可写，掉电保持（平台侧设置）。

## 6. 技术风险

| 风险 | 对策 |
|---|---|
| SysLib 定时器按扫描次数计时 | PR #89；上机前合并，不合并不上机 |
| TIA V19 无枚举，状态用 INT+常量，数值易错 | 数值表唯一来源 INT 第 8 节；测试用例逐步覆盖 |
| `.scltest` 与 plc check 的语言服务层只能在用户本机跑 | 云端只跑 plc_ci（结构、文档一致性、SCL 规范）；本机补跑插件 check / test |
| 平台轴对象与 `ST_ServoAxis` 的对接未在本仓库实现 | 另列“平台适配”任务，本方案不负责 |
| HMI 变量映射（旧 `hmi_tag_mapping.json` 是旧 ST 虚构的） | 以原 HMI 工程软元件为准重做映射（INT 第 7 节），HMI 工程另立 |

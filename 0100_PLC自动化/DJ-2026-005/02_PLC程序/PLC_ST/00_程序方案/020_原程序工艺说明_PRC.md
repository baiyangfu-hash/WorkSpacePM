## 0. 先看这一节（一分钟版）

1. 这台机器是一个 **“缓存 + 取放 + 送料”的三段流水**：4 层皮带输送机（每层一次放出一根）→ 取放料机构（X1 横移 + Z 升降 + 前后两个夹爪，一次夹两根）→ X2 送料小车（把 4 根一套的边框送到打胶机）。
2. 机器里有三个脉冲轴：**X1（轴1）、X2（轴2）、Z（轴3）**，三个模式 **手动 / 回原点 / 准备** 之后才能进 **自动**，另有 **暂停、HMI 停止、异常 M8、急停** 四种停法，行为各不相同（第 7 节）。
3. **“成对取料”的真实含义**：一次取 **两层**（3+4 层放小车前位，1+2 层放后位），两个夹爪各夹一根，同一个 X1 位置、同一个 Z 高度一起夹。你要的“单次取料”＝只取一层、一根，原程序没有，是新增模式（第 6 节）。
4. 我要你拍板的共 **8 个问题（第 9 节“必答”）**，每个都附了我的建议，回“按建议”即可。其余问题在第 9 节后半，不阻塞架构。
5. 我发现原程序自身有 **一批疑似毛病**（第 8 节）。新架构里是照搬还是改掉，要你逐类定。
6. 旧流程图（10-20 版）有 40 多处不对或不全，已被本文取代。

## 2. 模式总览

| 模式 | 进入 | 退出 | 要点 |
|---|---|---|---|
| **手动 M0** | HMI 直接置位 | HMI 复位；M8（异常）或 F12 存在时被强制复位，**异常存在期间进不了手动** | 进手动会强制退出自动 / 准备并取消回原点 |
| **回原点 M1** | X100 上升沿，且 无 M8、未回原点完成 M94、非手动、非自动、**无任何报警 SM62** | 三轴原点都到（M94）；M8、急停、切手动 | 因为要求“无报警”，M8 之后要按 **两次** X100（第一次清报警，第二次启动回原点）**【原】** |
| **准备 M2** | HMI 自动运行键 M6 上升沿，且 M94、非手动非自动、无报警 | 准备完成；M8、手动、F12 | **准备完成后自动进入自动**，不用再按键 |
| **自动 M4** | 准备完成（SM8044 上升沿），或 M6 上升沿 + SM8044 | 只有 M8、进手动、M1↑ 会退出 | **HMI STOP（F12）不退出自动**，只是冻结 |
| **暂停 M95** | HMI 置位 | HMI 复位（PLC 里没有解除逻辑） | 任何模式都可暂停；见第 7 节 |
| **异常 M8** | F0~F11（急停、8 扇门、3 个伺服）或 F13~F16（4 台变频器）任一 | 对应 F 全部复位后自动消失 | 见第 7 节 |

M8 之外的 F 报警（气缸、极限、有料、光电……）**不进 M8**，但在非手动时会触发“转移禁止 SM8040”，把自动**冻结**（不是停机）。

模式优先级：D116（设备状态给 HMI）按 **异常 > 暂停 > 自动 > 准备 > 回原点 > 手动** 显示，都没有时是待机。

## 3. 手动与示教

### 3.1 手动速度与点动
- 三个轴各有手动速度（X1 D2000 / X2 D2002 / Z D2004），HMI 加减键**按住期间每扫描 ±5**，范围约 500~5000。
- 点动 JOG：正向目标 +2,000,000，反向目标 **−200,000**（三个轴都是这样，相差 10 倍）**【疑】**。不检查回原点、不检查气缸和 Z 高度，只有硬极限保护。
- X2 的 JOG 不受组框机安全异常联锁约束；X2 的点位定位受。

### 3.2 手动定位到示教点
- X1：到 D510 / D520 / D540 / D550。前提：**Z 当前位置 ≤ 0**、**升降气缸在下位 X71**、已回原点 M94、手动。
- X2：到 D512 / D522。前提：已回原点、手动、X130、X131（两个无注释输入）、组框机无安全异常。**没有 Z 高度联锁**。
- Z：没有手动定位，只能点动。
- 夹爪和升降气缸 Y40~Y43：**梯形图里没有任何手动操作**（M67~M69 有注释但没用）**【疑】**。输送机的阻挡 / 分料 / 正反转有 HMI 强制位 M70~M90，不受模式门控，只在进手动、M0 变化、自动停、急停、M8 时清除。
- 输送机“上料按钮”M250~M253：只在“转移禁止（暂停或有报警）且取放料停在 S20”时才让该层正转，用于暂停时人工补料。

### 3.3 退出手动
- 进手动和出手动都会触发一整套复位（D760 小车步序清零、S20~S40、T100~T150、取料完成、M70~M90、Y44、Y47）；不复位夹爪和升降气缸，**不清 M94**。所以出手动后**不用重新回原点，但要重新准备**。

## 4. 回原点（M1）

### 4.1 预处理（只在 M1 期间）
1. 前夹爪松开位 1、2 都到（X67·X127）且升降缸不在下位 → 升降缸下降（SET Y43，RST Y42）。
2. 后夹爪任一松开位未到 → RST Y40；前夹爪任一松开位未到 → RST Y41。即“**无条件松开夹爪，不看夹爪里有没有料**”**【原，疑】**。

### 4.2 三轴顺序
1. **Z 先回**：要求升降缸在下位 X71，前后夹爪 4 个松开位都到，无转移禁止 → 回原点。
2. Z 完成（M123）后，**X1、X2 同时回**。X2 另要求“小车上无料”（F81 未锁）。
3. 完成 M94 = 三轴都回完。任何 F 报警都会暂停回原点（转移禁止），报警清除后**从头再回**。
4. 输送机同时做初始化：阻挡下降、分料升起、**反转 10 s** 把料退回上料端，完成后每层“准备完成”置位。

### 4.3 有料阻断
- 夹爪里有料（X60~X63 任一）→ F80；小车上有料（X72~X75 任一）→ F81。F80 同时锁住 Z 的所有定位。处理方式：人工取走再按 X100。

### 4.4 其他
- 回原点速度实际值疑似 K1000（各轴程序每扫描覆盖了系统运行写入的 K3000 / K5000 / K3000）**【疑】**，需现场监视确认。
- M94 只在 M8 时清除，所以**回原点完成后不能再主动回原点**（无“强制回原点”入口）。

## 5. 自动运行的工艺（核心）

### 5.1 总体节拍

```
4 层输送 ──每层把一根料送到“取料位”并发出 请求取料n──┐
                                                       ▼
X2 小车停在本机取料点 D512，车上光电告诉“前位空/后位空”
   → 发出 A 请求（前位）或 B 请求（后位）
                                                       ▼
取放料 S20~S25：X1 到取料点 → Z 升 → 两爪夹 → X1 横移 → Z 降 → 松开
   → 置“取料完成”（给输送）和“X1 前/后送料完成”（给小车）
                                                       ▼
前位、后位都放完（或 4 光电全亮 10 s 兜底）且 Z 在待机点
   → X2 小车去打胶机放料点 D522 → Y44 抓料可 → 打胶机取走
   → 4 个光电全灭（X102 或 10 s）→ 小车回 D512，重复
```

### 5.2 4 层输送机（每层相同；此处写的是“1 层”的动作，其余层同理）

**每层一个 10 步状态机**（FB 步序 0/1/2/10/20/30/50/60/70/80）：

| 步 | 做什么 | 转下一步的条件 |
|---|---|---|
| 0 分支 | 上电或复位后停这里。要“初始化” → 步 1；自动运行且取料机构在安全区时：取料位**空** → 步 10，取料位**已有料** → 步 60 | — |
| 1 状态判断 | 阻挡下降、分料升起 | 取料机构在安全区且 8 个气缸位置点全部符合 → 步 2 |
| 2 初始化 | **反转 10 s**（排空），完成后“准备完成”置位 | 10 s 到 → 步 0 |
| 10 放行 | 阻挡升起（需自动运行），分料升起；然后**快速正转** | 取料机构在安全区且阻挡 / 分料都在上位 → 步 20 |
| 20 运行到阻挡前 | 正转；**阻挡前到位光电一亮就开始计 3 s**（中途光电掉了也继续计） | 3 s 到，**停正转** → 步 30 |
| 30 分料下降 | 分料气缸下降，压住第 2 根 | 分料下位 2 点都到 → 步 50 |
| 50 阻挡下降 | 只有“取料位空且阻挡前有料”时才放下阻挡，让第 1 根通过 | 阻挡下位 2 点都到 → 步 60，否则原地等 |
| 60 送到取料位 | 取料机构在安全区内才**正转**；取料位两个开关都亮时**转慢速**并计 2 s；不在安全区则正转和计时都清零 | 2 s 到，停正转 / 慢速 → 步 70 |
| 70 请求取料 | 阻挡升起；条件满足后输出 **请求取料n = 1** | 请求发出 → 步 80 |
| 80 等取走 | 取料位两个开关都灭后，按“取料完成”是否已置位延时 **1 s（有）或 8 s（无）**（每扫描重新判断设定值） | 延时到 → 回步 10，继续下一根 |

**其他要点**
- **满料减速**：满料检测 1、2 同亮且正转时立即转慢速（任何步都有效）。
- **暂停时**（任何报警或 HMI 暂停）：正反转切断，**慢速、阻挡、分料保持**；5 个定时器的执行条件都带“非暂停”，定时器是非保持型（依据库说明，未实测）→ **暂停解除后重新计时，不是冻结续走**。**步序不冻结**。
- **异常停机（M8 或进手动）或一键退料的上升沿**：步序回 0，阻挡升起、分料升起、全部电机停、准备完成清零，必须重新初始化。
- **输送暂停来源**：SM8040 = (M95 暂停且非 X100 脉冲) 或 (任一 F 报警且非手动)。**所以任一层缺料超时（F100~F103）会让 4 层同时暂停**；按住 X100 期间暂停解除。**【原，疑】**
- **取料机构在安全区域**：自动时 = “不在 S22（夹紧）也不在 S23（横移）”（S21 也算安全）；手动 / 回原点 / 准备时 = “Z 当前位置 ≤ 待机点 D500”。夹料和横移时 4 层输送都不许动，正在送的立即停。
- **一键退料 M515**：HMI 置位，进 FB 步 1 要求非自动非初始化，所以只能在手动 / 回原点 / 准备下用；4 层“准备完成”都到位后自动清除。

### 5.3 取放料机构（S20~S25 状态机）

进入自动后，三轴都不动时 SET S20。

| 步 | 动作 | 转移条件 |
|---|---|---|
| **S20** X1 到取料位 / Z 到待机点 | 入口 0.5 s 内：松开两爪、清 4 个“取料完成”、装 Z 目标 = D500、装速度。0.5 s 后：**Z 先动到待机点，Z 到位（M45）后 X1 才动**；X1 还要 **A 或 B 请求** + 成对层请求都成立，且 A / B 出现满 0.5 s。A → X1 目标 D510；B → X1 目标 D540 | Z、X1 都到位 → S21 |
| **S21** Z 上升到取料位置 | 入口 0.5 s 内：升降气缸**上升**（SET Y42）。0.5 s 后，**前后夹爪 4 个松开位都到、4 个夹紧位都灭、层请求还在** → Z 上升到 Z 取料高度（3+4 层用 D514，1+2 层用 D544）。**Z 起升前不检查气缸上位 X70** | Z 到位 → S22 |
| **S22** 夹紧 | 升降气缸**上位 X70** 到 → **同一扫描 SET 前后夹爪 Y41 + Y40**。**本步无定时器** | 8 个夹紧 / 松开位符合（夹紧位全亮、松开位全灭）且 **X60~X63 四路产品检测全亮** → S23（转移条件**不含 X70**） |
| **S23** X1 到放料位置 | 入口 0.5 s 后：A → X1 去 D520（前放片点）；B → X1 去 D550（后放片点）。**只动 X1，Z 和夹爪、气缸不变** | X1 到位 → S24 |
| **S24** Z 到放料点 | 入口 0.5 s 内：**发“取料完成”**（A → 取料完成 4、3；B → 取料完成 2、1）并清对应“X1 送料完成”标志。**升降气缸下降**（Y43）一进步就执行；等**下位 X71 亮且上位 X70 灭**，Z 才下行到 D524（前后位共用） | Z 到位 → S25 |
| **S25** 夹爪松开 | 两爪松开 + 0.5 s；A 周期置 “X1 前送料完成”，B 周期置 “X1 后送料完成” | 松开位全到 → 回 S20 |

要点（和你最近一次读 PDF 不一样的几处）：
- S21 的名字是“Z **上升**到取料位置”，不是下降；放料才是“下降”。
- Z 在 S25 松开后**不抬升**，回待机是在下一轮 S20 入口；升降气缸 S25、S20 保持下降，到下一轮 S21 才升。
- “取料完成”在 **S24 进入 0.5 s 内**就发给输送机，这时料已被夹走并横移到小车上方，但还没放下。
- 夹爪、升降气缸 Y40~Y43 是 **SET / RST 自保持**，急停 / 异常 / 退出自动**都不复位**。
- 自动速度 D600：HMI 加减键每扫描 ±10；范围 10000~100000，**加到 100000 会被立刻重置回 10000（最低速）**。**【疑】**

### 5.4 成对取料（原程序的规则）

| 请求 | 条件 | 必须就绪的层 | X1 取料点 | Z 取料高度 | X1 放料点 | 取料完成 | 放完置位 |
|---|---|---|---|---|---|---|---|
| **A 前位** | 小车停 D512、4 个光电全灭、前位未放过 | **3 层 + 4 层**都有“请求取料” | D510 | D514 | D520 | 4、3 | X1 前送料完成 |
| **B 后位** | 小车停 D512、前位光电亮（X72·X73）、后位光电灭、后位未放过 | **1 层 + 2 层**都有“请求取料” | D540 | D544 | D550 | 2、1 | X1 后送料完成 |

- A 和 B 互斥，顺序固定：**先前位后后位**。前位没放完，1、2 层即使就绪也不会被取。
- 一次取料 = 两层各一根，前夹爪一根、后夹爪一根，**同一个 X1 位置、同一个 Z 高度**。一个位置共放 2 根，小车共 4 根 = 一套边框。**【推】**
- 程序里还有一个看不全名字的“边框送料 C”常闭，只出现在 B 的支路里，身份未定，见问题。

### 5.5 X2 送料小车（D760 四步序）

| 步 | 动作 | 转移条件 |
|---|---|---|
| **步 0** 回取料点 | 入口 0.5 s 装目标 D512。出发联锁：取放料在 S20、Z 到位（M45）、**Z 当前 = D500**、三轴都不在驱动中 | 到位 → 步 1 |
| **步 1** 取料点装料 | **仅当 X2 在 D512**：4 光电全灭且前位未放过 → A 请求；前位光电亮、后位灭且后位未放过 → B 请求；4 光电全亮计 10 s | “前、后位都放过” 或 “4 亮 10 s”，且 Z 在待机点、4 光电全亮、三轴不动 → 步 2 |
| **步 2** 去打胶机 | 入口 0.5 s 装目标 D522，**清两个 X1 送料完成标志**。出发条件：4 光电全亮 + 打胶机允许送料 X76 + 送框模式条件（见 5.6）+ 不在 D522 | 到位 → 步 3 |
| **步 3** 打胶机交互 | 到 D522 且 4 光电全亮 → **Y44 抓料可**（打胶机取走时一变灭就掉）；同时消耗一次“单套送框” | “4 光电全灭 10 s” 或 “4 光电全灭且 X102 取料完成”上升沿 → 回步 0 |

- Y47（给打胶机的安全区）= 小车在 D512、不在驱动中、自动模式。
- **X76 只在步 2 出发那一刻判断一次**；出发后掉了不停车。
- 暂停 / 报警冻结的是步序**译码**，不是 X2 本身：当前步里 X2 仍可起步、走完（**【原】**，旧文档“X2 冻结”的说法不准确）。
- 小车上有料时（F81）不能回原点。

### 5.6 与外部（组框机、打胶机）

- **送框模式**由 HMI 写 M501（CC-Link 智能站模式）、M502（连续送框）；程序里没有任何线圈驱动它们。M501 = 0 且 M502 = 0 时，**小车永远不会发往打胶机**。M501 = 1、M502 = 0 时，要组框机给 R5011.0 上升沿才放一套（单套送框 M510）。
- 本机发给组框机：R5000.0 = 急停 + 8 扇门任一。组框机发来：R5010.0 组框机安全异常（M501 = 1 时：禁止 X2 定位、触发转移禁止）、R5011.0 允许送料。
- Y45 组框机暂停 / Y46 组框机急停，以及 X160 / X161，在原程序里**被 /SM400 屏蔽或未使用**，实际不起作用。**【原，疑】**
- 链路异常按“清除”处理：R5010.0 变 0，联锁解除，只剩 F105 报警。

## 7. 停止、暂停、异常、急停的行为

| 情况 | 谁停 | 谁保持 | 怎么恢复 |
|---|---|---|---|
| **暂停 M95**（HMI） | 步进转移冻结；输送正反转切断；定位指令已在走的**走完** | 自动模式、STL 步、D760、M94、夹爪、气缸全保持 | HMI 复位 M95（PLC 无解除逻辑；X100 只能让 SM8040 断一个扫描）→ 原地继续 |
| **HMI STOP（F12）** | 同暂停（转移禁止）；同时 RST 手动、准备 | **自动 M4 保持，不退出** | 松开 STOP + X100 → 原地继续，不用回原点 |
| **其他 F 报警**（气缸、极限、有料、光电、缺料超时） | 同暂停（非手动时），输送线 4 层全暂停 | 同上 | 排除原因 + X100 → 继续 |
| **异常 M8**（F0~F11、F13~F16） | RST 自动 / 准备 / 回原点；输送正反转断；S20~S40、D760、定时器清；**M94 被清** | **夹爪 Y40~Y43 保持原状态** | 排除原因 → X100 清报警 → **再按 X100 回原点**（回原点预处理会松开夹爪，夹爪里有料会掉）→ M6 准备 → 自动 |
| **急停 X101** | 两条路同时：批量复位 + F0 → M8 | 同 M8 | 松开急停 + X100；**必须重新回原点** |
| **切手动** | 自动 / 准备退出，批量复位 | **M94 保留**，夹爪保持 | 退手动后按 M6 重新准备，不用回原点 |

M8 或急停时 PLC 只靠“断开定位指令驱动触点”让轴减速停止，没有伺服 OFF；是否还有硬件回路切电，程序里看不出来。

### 7.1 报警清单（概要）
- **进 M8**：F0 急停、F1~F8 门（左右各 4）、F9~F11 三个伺服、F13~F16 四台变频器。
- **不进 M8，经 SM8040 冻结**：F12 HMI 停止；F20~F25 三轴前后极限（**只在自动时报警**，复位条件也只看自动，退出自动后可复位）；F30~F33 夹料产品检测；F34~F65 每层 8 个气缸位置（5 s 超时）；F66~F75 取放料夹爪 / 升降缸位置（5 s 超时）；F80 / F81 回原点有料；F90 / F91 小车前 / 后光电异常（X1 报告放完但光电不全亮，1 s）；F100~F103 缺料超时（10 s，**F100 = 4 层，F103 = 1 层，编号和层号相反**）；F104 / F105 组框机安全异常 / 通讯异常。
- 报警都是自保持：**原因消失后按 X100 才复位**。

### 7.2 声光（杆灯、蜂鸣、按钮灯）
- 绿灯 Y24：手动 1 s 闪；**自动且无报警常亮**（暂停时仍亮）；回原点 / 准备 100 ms 闪。
- 黄灯 Y26：有报警 / 暂停 1 s 闪；回原点 / 准备 100 ms 闪；**M8 时灭**。
- 红灯 Y25：有报警（含 M8）/ 暂停 1 s 闪；**回原点 / 准备期间灭**。
- 蜂鸣 Y27：有报警、暂停、组框机安全异常时 1 s 断续；回原点 / 准备 100 ms 断续；HMI 静音 M9 可关。
- 复位按钮灯 Y50：有任何报警时 1 s 闪。

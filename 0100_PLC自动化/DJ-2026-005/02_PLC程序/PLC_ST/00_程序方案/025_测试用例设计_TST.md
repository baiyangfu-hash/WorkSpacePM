# 测试用例设计 DJ-2026-005 边框缓存机 PLC 程序

## 1. 文档基础信息

**文档版本**：V1.0.0　**编制日期**：2026-10-24　**编制人**：Claude　**审核人**：用户（待审）
**依据**：[REQ](需求分析文档_REQ.md)（R-* 编号）、[DSN](详细设计说明书_DSN.md)、[INT](接口文档_INT.md)
**顺序**：本文在**编码之前**交审；通过后才写 SCL。每个用例先于代码定义，编码后一一落成 `.scltest`。

## 2. 测试策略

| 层 | 内容 | 在哪跑 | 谁判 |
|---|---|---|---|
| L1 单 FB（`.scltest`） | 每个 FB 一个测试文件：基本 / 状态转移 / 边界超时 / 错误防呆 四段 | 用户本机语言服务（CI 的 Linux 上不跑，日志写明跳过） | 自动断言 |
| L2 联合（`.scltest`） | OB1 全链路：输送 + 取放料 + 小车 + 报警 的一个完整周期 | 用户本机 | 自动断言 |
| L3 plc check / 规范比对 | 语法白名单、命名、OB1 行数、CASE 有 ELSE | CI（Linux）+ 本机 | 自动 |
| L4 台架 / 现场 | 真机联调（含安全信号） | 现场 | 用户 |

- **定时器**：用户已确认“计时器、计数器不用仿真”（10-23）。因此 L1/L2 里对定时器只测**接线与设定值**（给足毫秒数后输出翻转，不再逐扫描验证 FB_TON 内部）。FB_TON 毫秒化（PR #89）合并前，测试以注入时钟 / 手动推进的方式运行；**上硬件前 #89 必须已合**。
- **安全信号**（急停、门、联锁）：自动测试通过后，仍需用户在 PR 上写“安全签字 + 提交号”后才能合并（项目规矩）。
- **每个用例**格式：编号 / 追溯 / 前置 / 步骤（输入）/ 期望输出 / 类别（基 = 基本，转 = 状态转移，界 = 边界与超时，防 = 错误与防呆）/ 安全相关。

## 3. 统一前置（RESET 段）

每个用例开头把相关结构体恢复默认：所有传感器按“安全空闲”态（气缸阻挡上位亮、分料上位亮、夹爪松开位亮、升降缸下位亮、轴不驱动），模式全 0，报警全清，步序 0。避免用例间状态污染（沿用旧测试文件的经验）。

# 使用说明 FB_1007_ConveyorSystem_BufferFraming

## 4 层输送系统（FB_1007_ConveyorSystem_BufferFraming）

4 层输送系统：持有 4 个 FB_1002 实例，把 ST_Io 的传感器和 Bridge / Machine 的命令搬到每层，把每层命令加上手动强制、上料点动后写到物理输出，汇总准备完成 / 请求 / 静止点，一键退料，气缸与缺料报警触发搬入 `stAlarm`。

要点：

1. 调用位置：OB1 第 6 个。
2. 时间参数是本 FB 的 `VAR CONSTANT`（毫秒）：反转 10000、阻挡前 3000、慢速 2000、取走后 1000 / 8000、缺料 10000、气缸 5000。
3. 一键退料 M515：非自动下上升沿，4 层 `bUnload` 置位；4 层都准备完成后清 M515。
4. 上料按钮 M250~M253：暂停或有报警、取放料在 S20、在安全区、无 M8 时点动对应层正转。
5. 手动强制位分组为假设（每层 5 位：阻挡 / 分料 / 正转 / 反转 / 慢速），待 HMI 工程核对。

## 调用

OB1 的调用行见 `00_主程序/OB1.scl`，实例声明见 `00_全局数据/GlobalVars.db`。

## 5. 状态机（从源程序提取的准确流程）

### 5.1 取放料机构（STL S20~S25，6步）

源程序使用三菱 STL (步进梯形图) 实现，非 Step_S 模式：

```
S20: Z待机位确认 → 等待取料请求信号 → 跳S21
S21: Z上升到取料高度 → Z到取片教点(D514) → 跳S22
S22: 夹紧确认 → 前后夹紧同时动作 →
     (后夹紧位1 & 前夹紧位1 & 后夹紧位2 & 前夹紧位2)=ON (4夹紧确认) →
     产品检测: 4光电全部=ON → 跳S23
S23: X1移动到放料位置 → 根据当前取料层选择前/后放料点
     (L1/L3→前放料点D520, L2/L4→后放料点D540) → 跳S24
S24: Z下降到放料高度 → Z到放片教点(D524) → 跳S25
S25: 夹紧松开 → 四组夹紧全部松开 →
     发送"放料完成"给送料机构 → 跳回S20
```

**与当前11步状态机的关键差异**:
- 源程序是 **6步**，当前代码是 **11步**
- 源程序无"产品检测"独立步，检测在S22步内完成
- 源程序"放料完成通知"和"松开"在同一S25步
- 源程序通过M150~M167管理夹爪时序

### 5.2 打胶机送料（D760步序，4步）

```
D760=0: 空闲 → 等待取放料"放料完成"信号 → D760=1
D760=1: X2移动到取料点(D620) → 到位 → D760=2
D760=2: X2移动到放料点(D630) → 到达打胶机位置 → 输出Y47(安全区关闭)
       → 等待打胶机允许送料(X76) → 输出Y44(允许抓料)
       → 等待打胶机取料完成(X102) → D760=3
D760=3: X2返回待机位(D610) → 输出Y47(安全区开放) → D760=0
```

**与当前6步状态机的关键差异**:
- 源程序是 **4步**，当前代码是 **6步**
- 源程序X2在"取料→送料"之前**不等待打胶机允许**，而是收到放料完成直接去取料位
- 当前代码的"等待取放料"和"等待打胶机允许"被拆分成了两步

### 5.3 四层输送机（FB Step_S 状态机）

源程序 FBD/LD 中通过"送料分料测试"FB 调用4次实现，每层使用的 Step_S 状态机步骤为：

```
Step 0: 初始化 → 输送反转复位到初始位 → 跳Step 1
Step 1: 等待分料前感应器ON(来料) → 跳Step 2
Step 2: 阻挡气缸下降(阻止后续来料) → 跳Step 10
Step 10: 输送正转 + 到位延时 → 双传感器到位 → 跳Step 20
Step 20: 阻挡气缸上升(释放) → 跳Step 30
Step 30: 分料气缸推出 → 跳Step 50
Step 50: 输送慢速 → 精准送到取料位 → 跳Step 60
Step 60: 请求取料 → 等待取放料取走 → 跳Step 70
Step 70: 分料气缸复位 → 跳Step 0
```

关键互锁信号:
- M8(安全门异常): 取反门控正/反转输出
- M515(取料机构在安全区): 互锁

**与当前FB_1002 8步状态机的关键差异**:
- 源程序有**复位/初始化步**(Step 0)，当前代码**无**
- 源程序先阻挡下降→输送正转→到位→阻挡上升→分料 **(分料在输送之后)**
- 当前代码是先阻挡→分料→复位→等待到位→输送→放料 **(分料在输送之前)**
- **工艺流程完全颠倒！这是最严重的差异。**

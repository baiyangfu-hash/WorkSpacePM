# 使用说明 06_模式与调度（FB_1001 / FB_1005 / FB_1006 / FB_2002）

## 机器模式（FB_1001_MachineMode_BufferFraming）

机器模式（手动 / 回原点 / 准备 / 自动）、暂停、停止收尾、设备状态字 D116，机器级报警触发 F0~F25（急停、8 扇门、伺服、变频器、HMI 停止、三轴极限）。

要点：

1. 调用位置：OB1 第 1 个。
2. M8（A 类锁存）清所有序列与“已回原点”；手动也强制退出。进手动不清已回原点，但须重新准备。
3. 回原点：复位键上升沿 ∧ 未回原点 ∧ 非手动 / 自动 / 准备 ∧ 无非提示类报警。
4. 自动运行键：已准备 → 直接进自动；否则先准备，准备完成自动进自动。
5. 停止：置 `bStopPending`，三类机构都在静止点后退出自动，保留已回原点与已准备标志。

## 回原点与准备（FB_1005_HomePrepare_BufferFraming）

回原点序列（预处理 → Z → X1/X2）与准备序列（夹爪 / 升降缸 → Z 待机点 → X1 取料点 → X2 取料点 → 等输送），F80 / F81，三个轴的使能与错误复位。

要点：

1. 调用位置：OB1 第 2 个。
2. 回原点预处理：夹爪有料（X60~X63）报 F80，不松夹爪，人工取走后按复位；否则松夹爪，前松开位到后升降缸下降。
3. 任何非提示类报警或暂停：撤销 `Home.Execute` / `Abs.Execute`，清除后在当前步重新发（“从头再回”）。
4. 回原点速度不在程序里：`ST_SvHome` 没有速度字段，由轴 / 驱动器参数决定（待现场确认 R-HOME-06）。
5. 准备速度取自动速度 D600；待机点 D500 ≤ 0 时写回默认 100。

## 手动与示教（FB_1006_ManualTeach_BufferFraming）

手动：速度加减、三轴点动、X1 / X2 手动定位、示教写点位、夹爪松开与升降缸手动、输送强制位放行。

要点：

1. 调用位置：OB1 第 3 个。
2. HMI 数组的轴序为 [1] = X1、[2] = X2、[3] = Z，与代码里的轴下标（Z = 1、X1 = 2、X2 = 3）不同。
3. 速度加减每次 ±5（上升沿 + 100 ms 重复，夹在 500~5000）；自动速度每次 ±500（步长新设）。
4. X1 手动定位要求已回原点、Z 不高于待机点 + 容差、升降缸下位；X2 要求已回原点、X130 与 X131、组框机无安全异常。
5. 输送强制位的电机三位在安全区外不放行（原程序无此限制，安全相关新增）。

## 站间中继（FB_2002_StationBridge）

站间信号中继：只做赋值（安全区、层请求、层取料完成、A / B 请求、X1 送料完成、Hold、回原点要求），外加三处最简组合（Hold = 报警 Hold 或暂停；送框许可；收到清除脉冲后清送料完成位），并把取放料 / 小车的报警触发搬入 `stAlarm`。

要点：

1. 调用位置：OB1 第 5 个；读上一扫描各机构的输出，信号一拍延迟。
2. 取放料 / 小车的 `arrTrig` 在此搬入 `stAlarm.arrTrig`（F30~F33、F66~F75、F106、F90、F91、F107）。
3. 同时汇总 `Machine.bAllAtRest` 供停止收尾判断，并把自动速度同步给小车。

## 2. 实现结构：公共报警（FB_2001_CommonAlarm_AllStation）

1. 两个 `FB_TON` 互相触发的方波振荡产生 1 s 与 100 ms 时钟。
2. 一次 `FOR` 扫描 128 位锁存，按 F 号区间归类：A = F0~F11、F13~F16、F104；取放料 = F20 F21 F24 F25、F30~F33、F66~F75、F106；小车 = F22 F23、F90 F91；输送 n 层 = F34~F65 每层 8 个与缺料 F103~F100；回原点 = F80 F81。
3. F12 / F105 / F107 为提示类，不进任何 Hold，也不点亮红灯用的 `bAny`，但参与最小报警号和闪烁条件。
4. 声光条件沿用 PRC 7.2 / DSN 9。

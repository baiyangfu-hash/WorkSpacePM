# 使用说明 FB_2001_CommonAlarm_AllStation

## 公共报警（FB_2001_CommonAlarm_AllStation）

F0~F127 报警自保持、分级（A 类进 M8，B 类按机构 Hold，提示类只显示）、最小报警号、复位键边沿清除和声光输出（杆灯绿 / 黄 / 红、蜂鸣、复位灯）。

要点：

1. 调用位置：OB1 最后一个；本扫描产生的 Hold / M8 下一扫描生效。
2. 各机构每扫描把触发写入 `stAlarm.arrTrig`（一位一写）；本 FB 只读触发、写锁存与分级输出。
3. 锁存规则：触发即锁；复位键（X100）上升沿且触发已消失才清除。
4. `iAlarmNo` = 最小锁存 F 号 + 1，0 表示无报警（避免 F0 急停与“无报警”重名，INT 原写“最小 F 号”，待确认）。
5. 静音 M9 关蜂鸣；M515 参与手动 / 回原点灯闪选项。

## 调用

OB1 的调用行见 `00_主程序/OB1.scl`，实例声明见 `00_全局数据/GlobalVars.db`。

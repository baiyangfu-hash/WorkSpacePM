# 里程碑表 - <项目号> <项目名>

> 用法：复制到项目的 `00_项目管理/01_立项与需求/004_<项目号>_里程碑表.md`（文件名必须以 `_里程碑表.md` 结尾，程序按这个名字找）。
> 驾驶舱总控屏的“到期倒数”只读这张表的**计划日期**；没填的阶段在屏上显示“到期未填”，不会编一个日期出来。
> `plc docs check` 会检查这张表：`项目来源: 新项目` 的计划日期没填直接拦住（退出码 1）；`项目来源: 老项目迁入` 的先只提示。
> 老项目迁入时把上面的 `项目来源` 改成 `老项目迁入`。

## 填写规矩（程序按这些读，别改表头和阶段名）

- 六个阶段固定，顺序固定：需求 → 设计 → 编程 → 仿真 → 现场 → 收尾。每个阶段一行，不加不减、不改名。
- **计划日期写这个阶段预计做完的日子**（到期倒数数到这一天），开始日期写在备注里。
- 日期只写 `YYYY-MM-DD`，例如 `2026-11-08`。不知道就留空或写 `待填`，**不要猜**，在备注里写该问谁。
- 状态只能写这四个词之一：`未开始`、`进行中`、`已完成`、`不适用`。
  - `已完成` 必须同时填实际日期。
  - 本项目确实没有这一阶段（例如纯测试套件没有现场）写 `不适用`，计划日期可以空着，备注写原因。
- 计划日期改了，在备注里写“原计划 YYYY-MM-DD，因 …… 改期”，不要直接抹掉旧日期的痕迹。

|---|---|---|---|---|

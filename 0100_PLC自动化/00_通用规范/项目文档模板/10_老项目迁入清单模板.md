## 2. 建骨架

- ☐ 由主执行在**控制根**用驾驶舱命令生成标准 PLC 项目，先预览再正式生成：
  `main.py project create --stack plc --mode standard-project --id <项目号> --name <项目名> --plc-vendor <品牌> --plc-model <型号> [--base-project <原项目号>] --dry-run`
  `--plc-vendor` 只认这几个英文写法：`Siemens`、`Mitsubishi`、`Omron`、`Keyence`、`Beckhoff`、`Delta`、`Other`。汇川等不在表里的品牌填 `Other`，真实品牌写进 `--plc-model`，例如 `--plc-vendor Other --plc-model "Inovance AM500"`。
  预览无误后去掉 `--dry-run` 再执行一次。项目生成在 `0100_PLC自动化/` 下；同名目录已存在时命令会报错停下，不会覆盖。
- ☐ **不要用** `main.py project import`：它把目录放进 Python 项目区，而且加 `--force` 时会先删掉同名目标目录。
- ☐ 生成的 `PM_SESSION_<项目号>.md` 已退役，原样留着，不填。
- ☐ 骨架里不需要的目录先空着，**不删**。

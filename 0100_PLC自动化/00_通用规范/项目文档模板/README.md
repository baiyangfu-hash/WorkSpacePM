## 2. 与已有变更单（CHG-PLC / CHG-ELEC / CHG-DOCU）的分工

- **业务变更记录**：回答“客户要改什么、谁批的”。一件事一行，任何人都看得懂。
- **CHG 变更单**：回答“工程上具体怎么改的”。改程序记 `CHG-PLC`，改电气图纸、IO、BOM 记 `CHG-ELEC`，改文档记 `CHG-DOCU`。仍按驾驶舱的变更单与台账流程走，这次没有改动。
- 两者的关联：业务变更行里的“关联 CHG / 提交”一栏，写对应的 CHG 编号或提交号。一条业务变更可以对应多张 CHG；纯工具或软件缺陷的 CHG（例如修驾驶舱技能）不算业务变更，不必登记到业务变更记录里。
- **业务变更记录不叫“台账”**：文件名不含“台账”二字，以免被驾驶舱的台账对账（`ledger reconcile`）和锁定清单当成 CHG 台账处理。

## 3. 填写约定

- 工艺流程图：一张 Mermaid 图配一张步序表，步号与程序里的步序变量一致，每一步写超时和报警码（STD-850、STD-860）。

- 不知道的就写 `待补`，**不要猜**。`待补` 后面用括号写清楚该问谁、该查哪份资料。
- 日期统一用 `YYYY-MM-DD`；型号写到具体料号。
- 与原设备（被改造的旧机）有关的事实，注明出处文件，例如 `DJ-2026-005 012 需求规格 §5.1`。
- 发现两份文档互相矛盾时，不要自己挑一个，在文档末尾的“待确认”一节列出来。

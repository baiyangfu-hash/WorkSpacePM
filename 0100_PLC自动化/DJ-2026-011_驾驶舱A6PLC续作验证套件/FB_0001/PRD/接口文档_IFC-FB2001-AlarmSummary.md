# 接口文档（IFC）- FB_2001_AlarmSummary_DJ2026011

> 功能块: FB_2001_AlarmSummary_DJ2026011
> 项目: DJ-2026-011 驾驶舱A6PLC续作验证套件
> 版本: V1.0.1
> 依据: INT-815 PLC接口文档模板 / LSP-905 SCL编程规范

## 1. 功能说明

报警汇总与锁存报警灯功能块。汇总 16 路报警输入，任意一路为 TRUE 时点亮报警灯并保持；报警全部消失后，按复位按钮的上升沿熄灭报警灯；报警仍在时按复位无效。

## 2. 接口参数

### 2.1 VAR_INPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| i_arrAlarms | ARRAY[1..16] OF BOOL | 16 路报警输入, 任意一路 TRUE 表示有报警 |
| i_bReset | BOOL | 复位按钮 (上升沿有效, 按下=TRUE) |

### 2.2 VAR_OUTPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| o_bAlarmLamp | BOOL | 报警灯输出, 报警锁存后保持点亮 |
| o_bAnyAlarm | BOOL | 报警汇总结果, 当前任一路报警为 TRUE |

## 3. 调用约定

- 功能块为单实例调用，实例位于 `DB_AlarmSummaryTest.fb_AlarmSummary`。
- `i_arrAlarms` 必须传入长度 1..16 的 BOOL 数组，下标从 1 开始。
- 复位按钮必须传电平信号，功能块内部取上升沿，无需外部做沿检测。
- 报警灯和报警汇均为电平输出，可直接驱动指示灯或上位机读取。

## 4. 逻辑说明

1. 每个扫描周期先遍历 `i_arrAlarms[1..16]`，任意一路为 TRUE 时 `o_bAnyAlarm` 置 TRUE。
2. `i_bReset` 经 `FB_R_TRIG` 取上升沿，得到单周期复位脉冲。
3. 锁存逻辑：`o_bAnyAlarm` 为 TRUE 时置位 `s_bAlarmLatch`；仅当 `o_bAnyAlarm` 为 FALSE 且复位脉冲到来时清零。
4. `o_bAlarmLamp` 直接输出锁存状态，因此报警消失后灯仍亮，直到按复位；报警仍在时复位不生效。

## 5. 测试用例

| 用例编号 | 用例名称 | 预期结果 |
|---------|---------|---------|
| TC-2001-01 | 无报警时按复位 | 报警灯保持熄灭 |
| TC-2001-02 | 任一路报警 | 报警灯点亮 |
| TC-2001-03 | 报警消失后锁存 | 报警灯保持点亮，按复位后熄灭 |
| TC-2001-04 | 报警仍在时按复位 | 报警灯不熄灭 |
| TC-2001-05 | 第 16 路边界报警 | 报警灯点亮并锁存 |
| TC-2001-06 | 双手启动同步故障联动 | 第 1 路报警点亮报警灯 |

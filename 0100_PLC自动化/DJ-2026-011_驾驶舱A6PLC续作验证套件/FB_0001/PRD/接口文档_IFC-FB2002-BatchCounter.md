# 接口文档（IFC）- FB_2002_BatchCounter_DJ2026011

> 功能块: FB_2002_BatchCounter_DJ2026011
> 项目: DJ-2026-011 驾驶舱A6PLC续作验证套件
> 版本: V1.0.0
> 依据: INT-815 PLC接口文档模板 / LSP-905 SCL编程规范

## 1. 功能说明

批量计数功能块。光电传感器每检测到一个工件计一件，计数达到设定数量时输出批次完成并保持；按复位按钮的上升沿清零计数并重新计数。批次完成后继续来件不再累加；设定数量小于等于 0 时不计数也不完成。

## 2. 接口参数

### 2.1 VAR_INPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| i_bPhotoSensor | BOOL | 光电传感器信号, 每来一件产生一个上升沿, 按下=TRUE |
| i_dBatchTarget | DINT | 批次设定数量, 小于等于 0 时禁用计数 |
| i_bReset | BOOL | 复位按钮 (上升沿有效, 按下=TRUE) |

### 2.2 VAR_OUTPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| o_dBatchCount | DINT | 当前批次已计工件数 |
| o_bBatchComplete | BOOL | 批次完成输出, 达到设定数量后保持到复位 |

## 3. 调用约定

- 功能块为单实例调用，实例位于 `DB_BatchCounterTest.fb_BatchCounter`。
- 光电信号必须传电平信号，功能块内部取上升沿，无需外部做沿检测；信号长亮只计一件。
- 复位按钮必须传电平信号，功能块内部取上升沿，长按不会反复清零。
- `i_dBatchTarget` 为 DINT 毫秒无关的纯计数值，运行中可修改；完成后需复位才会按新设定值重新计数。
- `o_dBatchCount` 与 `o_bBatchComplete` 均为电平输出，可直接驱动指示灯或上位机读取。

## 4. 逻辑说明

1. `i_bPhotoSensor` 与 `i_bReset` 分别经 `FB_R_TRIG` 取上升沿，得到单周期脉冲 `s_bPhotoPulse` 与 `s_bResetPulse`。
2. 复位优先：复位脉冲到来时 `o_dBatchCount` 清零、`s_bBatchLatch` 清零，随后重新计数。
3. 计数：未完成且 `i_dBatchTarget > 0` 时，每个光电上升沿 `o_dBatchCount` 加 1。
4. 完成：`o_dBatchCount` 达到 `i_dBatchTarget` 时钳位到设定值并锁存 `s_bBatchLatch`，`o_bBatchComplete` 输出锁存状态，之后不再累加。
5. 设定数量小于等于 0 时既不累加也不置完成，复位仍可清零。

## 5. 测试用例

| 用例编号 | 用例名称 | 预期结果 |
|---------|---------|---------|
| TC-2002-01 | 复位后计数清零 | 计数为 0, 批次未完成 |
| TC-2002-02 | 3 个光电上升沿 | 计数为 3, 批次未完成 |
| TC-2002-03 | 光电长亮 10 个周期 | 只计 1 件 |
| TC-2002-04 | 计满 5 件 | 计数值保持 5, 批次完成 |
| TC-2002-05 | 完成后再来一件 | 计数保持 5, 完成保持 |
| TC-2002-06 | 完成后复位再计 2 件 | 复位后为 0, 再计为 2 |
| TC-2002-07 | 设定数量为 1 | 首件即批次完成 |

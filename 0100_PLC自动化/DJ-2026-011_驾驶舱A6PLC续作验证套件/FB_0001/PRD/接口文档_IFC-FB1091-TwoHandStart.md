# 接口文档（IFC）- FB_1091_TwoHandStart_DJ2026011

> 功能块: FB_1091_TwoHandStart_DJ2026011
> 项目: DJ-2026-011 驾驶舱A6PLC续作验证套件
> 版本: V1.0.0
> 依据: INT-815 PLC接口文档模板 / LSP-905 SCL编程规范
> 安全属性: 双手启动，属安全区逻辑（本块只验证双手同步逻辑，不能替代安全继电器与硬接线）

## 1. 功能说明

双手启动功能块。两个启动按钮须在同步窗口内（默认 500 ms，可调）先后按下并一直按住才输出启动；任一松开立即停止；两个都松开后才允许下一次启动；同一扫描周期双手同步按下视为满足同步窗口。单手持按超过同步窗口置同步故障，双手全部松开后故障清除。

## 2. 接口参数

### 2.1 VAR_INPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| i_bStartLeft | BOOL | 左启动按钮 (按下=TRUE) |
| i_bStartRight | BOOL | 右启动按钮 (按下=TRUE) |
| i_dSyncWindowMs | DINT | 双手同步窗口毫秒值, 500 = 0.5s |

### 2.2 VAR_OUTPUT

| 参数名 | 类型 | 说明 |
|--------|------|------|
| o_bStartOutput | BOOL | 双手启动输出, 双手按住时保持 TRUE |
| o_bSyncFault | BOOL | 同步故障: 单手持按超过同步窗口 |

## 3. 调用约定

- 功能块为单实例调用，实例位于 `DB_TwoHandStartTest.fb_TwoHandStart`。
- 两个按钮传电平信号（按下=TRUE），功能块内部不做取沿，无需外部做沿检测。
- 同步窗口 `i_dSyncWindowMs` 为毫秒，由调用方传入常量（默认 500），功能块内部使用 `FB_TON` 计时（SysLib，按真实毫秒计时）。
- `o_bStartOutput` 只表示“双手同步按住”这一逻辑条件，不是安全信号；急停、安全门等安全回路由安全继电器与 `FB_1030_SafetyManager` 负责。

## 4. 逻辑说明

状态机 `s_iStep`（CASE 带 ELSE 防死锁，异常步序回到 0）：

| 步序 | 含义 | 转移 |
|------|------|------|
| 0 | 空闲 | 清同步故障；双手同时按下 → 20；单手按下 → 10 |
| 10 | 等待第二只手 | 双手按下 → 20；全部松开 → 0；同步窗口到时 → 置同步故障并转 30 |
| 20 | 运行 | 任一松开 → 30 |
| 30 | 等待释放 | 双手都松开 → 0 |

输出 `o_bStartOutput` 仅在步序 20 且双手仍按住时为 TRUE，任一松开当扫描即断开。

## 5. 测试用例

| 用例编号 | 用例名称 | 预期结果 |
|---------|---------|---------|
| TC-1091-01 | 双手同一扫描周期按下 | 立即输出启动，无同步故障 |
| TC-1091-02 | 先后按下且间隔小于同步窗口 | 输出启动，无同步故障 |
| TC-1091-03 | 单手持按超过同步窗口 | 不输出，置同步故障 |
| TC-1091-04 | 运行中松开任一按钮 | 立即停止输出 |
| TC-1091-05 | 未全部松开再次按下 | 不允许再次启动 |
| TC-1091-06 | 双手全部松开后再按下 | 允许下一次启动 |

用例脚本：`Test/two_hand_start_test.scltest`（test1～test6）。LSP 的 `.scltest` 只验证逻辑，不替代 PLCSIM 或实机验证。
